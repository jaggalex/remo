# SyncStatus

Статус синхронизации словами: saved, pending, offline — одно место в топбаре, без спиннеров.

## Когда
- Ровно одно место — TopBar (паттерн 4). Это то, чего не хватает референсу: офлайн и сохранение всегда видны (П4).
- ReadOnlyBadge — рядом с названием доски, если у пользователя нет прав на редактирование.

## Состояния
saved · pending · offline. Остальные не применимы: статус только читается, объявляется через `aria-live`.

## Потребитель передаёт
- `state`: `saved` | `pending` | `offline`; `short` — короткая форма для топбара (полная — в `title`).

## Правила
- Объявляется через `aria-live="polite"`. Текст: «Сохранено», «Сохраняется…», «Нет сети — правки сохранены локально».
