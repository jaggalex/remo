# VoteCard

Карточка голосования: сколько голосов осталось, таймер, завершение; итог или пустое состояние.

## Правила
- Остаток голосов — точками **и** числом «3 / 5» (не только цвет).
- Завершить может только фасилитатор (`canEnd`); у участника кнопки нет — и это видно по метаданным («Запустил Алекс»).
- Завершено без голосов — пустое состояние словами «Никто не проголосовал».

## Состояния
active · ended · empty · canEnd. Остальные не применимы: кнопки внутри.

## Потребитель передаёт
- `title`, `meta`, `left`, `total`, `timer`, `timerTotal`, `state` (`active` | `ended`), `canEnd`, `onEnd`, `empty`, `children` (итоги).
