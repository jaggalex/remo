# FollowIndicator

Индикатор «Слежу за Alex»: рамка вокруг вьюпорта и плашка с именем и кнопкой «Остановить».

## Когда
- Участник включил follow; вьюпорт зеркалит другого человека.
- Остановка доступна с двух сторон: у следящего и у того, за кем следят (ADR-076).

## Анатомия
Плашка: иконка `eye`, «Слежу за {name}», кнопка «Остановить»; цвет — `presence-N` ведущего; рамка 1.5 px по краю доски.

## Состояния
following. Остальные не применимы: индикатор управляет одним действием — остановкой.

## Потребитель передаёт
- `name`, `color`, `onStop`.

## A11y
- `role="status"`, `aria-live="polite"`; кнопка «Остановить» достижима с клавиатуры.

## Нельзя
- Оставлять follow без видимой остановки.
- Следить молча: человек должен видеть, что за ним следят, и уметь это прекратить.
