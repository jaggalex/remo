# Switch

Мгновенное включение/выключение: публичная ссылка, уведомления, режим.

## Когда
- Настройка применяется сразу, без формы и кнопки «Сохранить».
- Для выбора из вариантов — `Radio`/`Select`; для подтверждения перед действием — `Checkbox`.

## Анатомия
Дорожка 28×16, большой палец 12 px, подпись справа; `input type="checkbox" role="switch"`.

## Состояния
default · hover · focus-visible · disabled · selected (включён). active, loading, error, read-only — не применимы.

## Потребитель передаёт
- `checked`/`onChange`, `label`, `disabled`.

## A11y
- `role="switch"` и `aria-checked`; подпись кликабельна; фокус-кольцо на дорожке, не на скрытом input.

## Нельзя
- Ставить в форму с кнопкой «Сохранить»: состояние применится дважды.
- Прятать последствия: выключение ссылки — это потеря доступа, рядом должно быть объяснение.
