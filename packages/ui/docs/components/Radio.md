# Radio

Один выбор из видимых вариантов: область действия агента, режим ссылки, плотность в каталоге.

## Когда
- Вариантов 2–5 и все должны быть видны. Для 6+ — `Select`; для независимых переключателей — `Checkbox`.
- Выбор применяется сразу, без кнопки «Сохранить»; если нужен черновик — это `Checkbox` внутри формы.

## Анатомия
`label` (кликабельная строка), круг 16 px, `input type="radio"`, подсказка `hint`.

## Состояния
default · hover · focus-visible · disabled · selected (checked). active, loading, error, read-only — не применимы.

## Потребитель передаёт
- `name`, `value`, `defaultChecked`/`checked`, `onChange`, `label`, `hint`.

## A11y
- Нативный `input type="radio"` внутри `label`; группа — `fieldset`/`legend` на стороне потребителя; фокус двигается стрелками.

## Нельзя
- Пустая группа без ни одного выбранного варианта, если выбор обязателен: добавьте `defaultChecked` или пояснение.
- Один вариант: это `Checkbox`, не `Radio`.
