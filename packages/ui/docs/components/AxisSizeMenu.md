# AxisSizeMenu

Размер колонки или строки: «Авто» по умолчанию, «Вручную» — пресеты или пиксели.

> **Статус:** спроектирован, в коде нет. Макеты — холст «REMO — визуальные направления»; решение — ADR-196; экран T13.

## Анатомия
Заголовок «Ширина колонки «…»» / «Высота строки «…»»; `Segmented` Авто / Вручную; подпись
правила «Авто»; в «Вручную» — `Segmented` Узкая / Средняя / Широкая (Низкая / Средняя / Высокая)
и значение в px; подсказка клавиш.

## Поведение
- «Авто»: по крайним объектам оси плюс небольшой отступ; пустая ось — под один объект.
- Перетаскивание границы (`AxisResizeHandle`) переключает в «Вручную»; двойной клик — обратно в «Авто».
- Ручной размер не меньше объектов в оси: объекты не сжимаются и не обрезаются.

## A11y
- Alt+←/→ — ширина, Alt+↑/↓ — высота; новое значение объявляется.
