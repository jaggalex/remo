# Menu

Меню и контекстное меню: пункты с иконкой и шорткатом, чекбоксы, разделители, destructive отдельной группой.

## Когда
- Выпадающее меню кнопки «⋯», контекстное меню правого клика и `Shift+F10` — один и тот же компонент.

## Правила
- Destructive-пункт (`danger`) — последним, отделён разделителем, красным текстом (П6). Не рядом с «Заблокировать».
- Пункт, который ведёт к подтверждению, заканчивается многоточием: «Удалить…».
- Стрелки ↑/↓ двигают фокус, `Esc` закрывает и возвращает фокус на кнопку-источник.

## Состояния
default · hover · active · focus-visible · disabled · selected (checked). loading, error, read-only — не применимы; danger — вариант пункта, а не состояние.

## Потребитель передаёт
- `items`: `{label, icon?, shortcut?, hint?, checked?, disabled?, danger?, submenu?, onSelect}` | `{separator:true}` | `{heading}`; `label` для `aria-label`; `onClose`.
