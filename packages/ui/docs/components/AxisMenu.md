# AxisMenu

Меню заголовка оси: всё, что можно сделать с колонкой или строкой.

> **Статус:** в коде (E6.5). Макеты — холст «REMO — визуальные направления»; решение — ADR-196; экраны T7, T9, T13, R9.

## Анатомия
`Menu`: Переименовать · Вставить колонку слева / справа (у строки — сверху / снизу) ·
разделитель · Переместить влево / вправо (вверх / вниз) · Повернуть заголовок (только колонки,
с галочкой) · Размер → `AxisSizeMenu` · разделитель · Удалить колонку… / строку…

## Поведение
- Каждый пункт — одна операция и один undo.
- «Удалить…» у оси с объектами открывает подтверждение: перенести в соседа (только существующего)
  или удалить вместе с объектами; по умолчанию — перенос. Пустая ось удаляется сразу.
- Перемещение недоступно у крайней оси в эту сторону — пункт не показывается.

## Нельзя
- Предлагать соседа, которого нет.
- Удалять объекты без вопроса.
