# Button

Единственное действие в контексте: primary, secondary, ghost, danger; 28 (compact) и 32 (default).

## Когда
- **primary** — одно на диалог/панель (П2). Это главное действие: «Поделиться», «Запустить агента».
- **secondary** — второстепенные действия рядом с primary («Отмена»).
- **ghost** — действия в тулбарах и строках таблиц.
- **danger** — только в подтверждении удаления/отзыва; всегда справа и с числом объектов.
- Не используется для навигации — для этого Link.

## Размеры и плотность
- `default` 32 — формы и диалоги; `compact` 28 — панели, меню, тулбары. Без `size` высота берётся из `--control-h` (переключается `[data-density="compact"]`).

## Состояния
default · hover · active · focus-visible · disabled · loading; `selected` — только для кнопок-переключателей (`selected={true|false}` → `aria-pressed`). read-only не применяется: кнопка скрывается или disabled.

## Потребитель передаёт
- `children` — глагол в инфинитиве («Удалить», «Скопировать ссылку»), без «пожалуйста».
- `icon` / `iconEnd`, `loading`, `disabled`, `onClick`.

## Нельзя
- Две primary в одном диалоге (Dialog предупреждает в консоли).
- Перенос текста: подпись ≤ `label-max` (240 px), длиннее — ellipsis и укорачиваем текст.
- Цвет как единственный признак состояния: disabled/loading меняют и курсор, и `aria-*`.
