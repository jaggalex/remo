# PublicLink

Блок «Ссылка для всех» в Share: состояние (выкл / пароль / срок), предупреждение о последствиях, копирование.

## Правила (паттерн 1)
- Отдельный блок под списком субъектов. Состояние — словами в одной строке: «Включена · читатель · без пароля · до 31.10.2026».
- Включена без пароля — Banner warning с последствием и что сделать.
- Выключена — объясняет, кто может открыть доску.
- Switch применяется сразу, без кнопки «Сохранить».

## Состояния
off · on · on + password · on + expiry. Девять интерактивных состояний не применимы: переключатель — `Switch`, ссылка — `Input read-only`.

## Потребитель передаёт
- `enabled`, `role`, `password` (bool), `expires` (строка через `Intl.DateTimeFormat`), `url`, `onToggle`, `onCopy`.
