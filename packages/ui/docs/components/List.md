# List

Двухстрочный список внутри панели и диалога: заголовок, метаданные, ведущий и замыкающий элемент.

## Когда
- История в инспекторе, участники в организации, короткие перечисления, где `Table` избыточна.
- Для табличных данных с колонками — `Table`, не `List`.

## Анатомия
`[leading?] заголовок / meta [trailing?]`; разделители — `border-subtle`; строка не кликабельна целиком, действия — в `trailing`.

## Состояния
default · empty. Остальные не применимы: список — данные; hover, active, focus-visible принадлежат действиям в `trailing`.

## Потребитель передаёт
- `items`: `{id?, title, meta?, leading?, trailing?}`.

## A11y
- `ul`/`li`; декоративные аватары и иконки — `aria-hidden`; у действий в `trailing` обязательна подпись или `aria-label`.

## Нельзя
- Делать строку кнопкой без причины: фокус должен быть на конкретном действии.
- Прятать смысл в цвет: статус — словом или `Badge`.
