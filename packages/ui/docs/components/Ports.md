# Ports

Восемь якорей по периметру фигуры: адрес для связи, а не украшение.

## Когда
- Hover или выделение фигуры в режиме связи; `connected` — занятый порт.
- Порты — оверлей в DOM; сама фигура на доске рисуется Canvas 2D.

## Анатомия
8 точек 8 px (зона захвата 12 px): 4 стороны + 4 угла; `hidden` → `visible` на hover; `hot` — под курсором, 12 px; `connected` — залит `selection-stroke`.

## Состояния
hidden · visible · hot · connected. hover, active, focus-visible, disabled, loading, error, read-only, selected — не применимы к самому оверлею: состояния задаёт объект.

## Потребитель передаёт
- `width`, `height`, `label`, `hot` (индекс), `connected` (индексы), `visible`.

## A11y
- Контейнер фокусируем (`tabIndex=0`), у каждого порта есть `aria-label` с направлением. Клавиатурный обход портов по `Tab` — этап 1.6 дорожной карты.

## Геометрия
Размеры в единицах доски; на экране точки не масштабируются с зумом (константные 8/12 px).

## Нельзя
- Делать порт визуальным декором без адреса: конец связи — ссылка на объект и порт (ADR-077).
- Показывать все 8 портов постоянно: шум на холсте.
