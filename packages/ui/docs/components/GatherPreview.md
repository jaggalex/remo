# GatherPreview

Пунктир будущего раздела, пока указатель или фокус на «Собрать в раздел».

> **Статус:** в коде (`apps/web/src/GatherPreview.tsx`). Решение — ADR-198, ADR-201; экраны T2, P6.

## Анатомия
Прямоугольник по выделению с отступом раздела: пунктир 1.5 px `accent`, заливка `accent-soft`,
`radius-sm`; над ним подпись «Раздел» (`type-caption`, `text-accent`). Не перехватывает указатель.

## Поведение
- Рамка берётся из той же функции (`gatherPlan`), что создаёт раздел: превью и результат совпадают.
- Исчезает при уходе с кнопки, по клику и если в выделении меньше двух подходящих объектов.

## A11y
- `aria-hidden`: последствие называет сама кнопка и её подсказка; превью — дополнительная картинка.
