# Panel

Инспектор справа 276 px: шапка, секции, свойства и счётчики; ничего, что дублирует холст.

## Правила (паттерн 2)
- Ширина `inspector-width` (276 px) на любой ширине окна; скроллится только тело.
- Секции (PanelSection) отделены границей; заголовок секции — `caption`-размер, `text-secondary`.
- Значения — Property (ключ слева, значение справа, `numeric` — табличные цифры).
- Пустое состояние «Ничего не выбрано» — EmptyState без кнопки.
- Источник прав показывается словами (П7): «Заблокировал Алекс», «Редактор через команду PM».

## Состояния
default · empty. Остальные не применимы: панель — контейнер.

## Потребитель передаёт
- Panel: `title`, `actions`, `children`. PanelSection: `title`. Property: `label`, `children`, `numeric`.
