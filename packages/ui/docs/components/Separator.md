# Separator

Тонкая линия между группами: горизонтальная в меню, диалоге и панели, вертикальная между действиями в тулбаре.

## Когда
- Разделяет группы по правилу близости (П3), а не «для красоты».
- В меню destructive-группа отделяется всегда (П6).

## Анатомия
1 px `border-subtle`; горизонтальный — `space-2` по вертикали, вертикальный — высота 20 px и `space-1` по бокам.

## Состояния
default. Остальные не применимы: разделитель декоративен.

## Потребитель передаёт
- `vertical`.

## A11y
- `hr`; при вертикальном — `aria-orientation="vertical"`. Смысл не передаёт, поэтому в дерево доступности может не попадать.

## Нельзя
- Заменять отступы: сначала `space-*`, разделитель — только между смысловыми группами.
- Красить в `border-strong`: это граница поля, а не декор.
