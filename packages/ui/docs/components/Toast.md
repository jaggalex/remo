# Toast

Уведомление на 5 с через aria-live: info, success, warning, danger; undo — действием в тосте.

## Правила
- Живёт 5 с (danger — пока не закроют), стопка в правом нижнем углу, слой `z-toast`.
- Текст = что случилось + что сделать. Без «успешно» и восклицательных знаков.
- Удаление → тост с «Отменить» вместо подтверждения, если действие обратимо.

## Состояния
neutral · info · success · warning · danger · with action · dismissable. Девять интерактивных состояний не применимы: тост — сообщение, действия внутри — кнопки.

## Потребитель передаёт
- `tone`, `title`, `children`, `action` (`{label, onClick}`), `onClose`.
