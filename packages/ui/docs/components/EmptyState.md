# EmptyState

Пустое состояние: что это, зачем, одно действие и пример.

## Правила (паттерн 5)
- Заголовок называет, что здесь будет; текст — зачем; одна primary-кнопка; пример — `caption` под ней.
- Используется в каталоге досок, инспекторе («Ничего не выбрано»), журнале, списке агентов.

## Состояния
default · with action · with example. Остальные не применимы: пустое состояние не интерактивно, действие — `Button`.

## Потребитель передаёт
- `icon`, `title`, `children`, `action` (`{label, icon?, onClick}`), `example`.
