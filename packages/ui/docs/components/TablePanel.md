# TablePanel

Панель выбранного раздела: вид «Свободно / Таблица», оси, размер, оформление и два удаления
с последствиями словами.

> **Статус:** в коде (E6.4). Макеты — холст «REMO — визуальные направления»; решение — ADR-196; экраны T1, T3, T5–T8, T13, P7.

## Когда
- Выбран один раздел (фрейм). В режиме таблицы — все группы; в свободном — вид, оси и «Удалить раздел».

## Анатомия
`Panel` справа (тонкая линия, `radius-xl`; на 1024 — оверлей 280 px). Сверху вниз: «Раздел» +
имя; «Вид» — `Segmented` + подпись «Только для этого раздела»; «Оси» — две кнопки `quiet`
с «+»; «Размер» (если выбрана ось): `Segmented` Авто / пресеты и поле «Вручную» в px;
«Оформление таблицы» — свёрнутая строка, только в режиме таблицы; внизу «Убрать таблицу»
(`secondary`) и «Удалить раздел» (`danger`), под каждой — последствие `caption`; у удаления —
число объектов, которые останутся на холсте. «Переместить в ячейку…» — не здесь, а в свойствах
выделенного объекта (`CellDropTarget`, ADR-201).

## Состояния
free · table · axis-selected · manual-size (px) · look-open · remove-disabled («Таблицы ещё нет») ·
read-only (только чтение: группы без действий).

## A11y
- Группы — `section` с заголовками; «Оформление таблицы» — `button` с `aria-expanded`.
- Выключенная «Убрать таблицу» — `disabled`, причина — подписью под ней.
- Поле px: Enter — применить, Esc — вернуть.

## Нельзя
- Выносить оформление на холст или в панель объекта.
- Писать «Удалить таблицу»: таблица убирается, объекты остаются.
