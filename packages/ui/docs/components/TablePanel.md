# TablePanel

Панель выбранного раздела: вид «Свободно / Таблица», оси, размер, оформление и два удаления
с последствиями словами.

> **Статус:** спроектирован, в коде нет. Макеты — холст «REMO — визуальные направления»; решение — ADR-196; экраны T1, T3, T5–T8, T13, P7.

## Когда
- Выбран один раздел (фрейм). В режиме таблицы — все группы; в свободном — вид, оси и «Удалить раздел».

## Анатомия
`Panel` справа (тонкая линия, `radius-xl`; на 1024 — оверлей 280 px). Сверху вниз: «Раздел» +
имя; «Вид» — `Segmented` + подпись «Только для этого раздела»; «Оси» — две кнопки `quiet`
с «+»; «Размер» (если выбрана ось); «Объект» (если выбрано содержимое) — «Переместить в ячейку…»;
«Оформление таблицы» — свёрнутая строка; внизу «Убрать таблицу» и «Удалить раздел», под каждой —
последствие `caption`.

## Состояния
free · table · axis-selected · object-selected · look-open · remove-disabled («Таблицы ещё нет») ·
read-only (только чтение: группы без действий).

## A11y
- Группы — `section` с заголовками; «Оформление таблицы» — `button` с `aria-expanded`.
- Выключенная «Убрать таблицу» остаётся фокусируемой и объясняет причину.

## Нельзя
- Выносить оформление на холст или в панель объекта.
- Писать «Удалить таблицу»: таблица убирается, объекты остаются.
