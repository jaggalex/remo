# AxisHeader

Заголовок колонки или строки таблицы раздела: редактируемый текст, а не служебная шапка.

> **Статус:** спроектирован, в коде нет. Макеты — холст «REMO — визуальные направления»; решение — ADR-196; экраны T5–T7, T9, T13.

## Анатомия
Текст `label` 600 на фоне `bg-hover`-тона шапки (или переопределённом фоне); у колонки — по
горизонтали, по команде — вертикально (только колонки). Угол таблицы пустой. Нет A/B/C и 1/2/3.

## Состояния
default · selected (кольцо `border-focus`) · editing (поле, каретка, подсказка Enter/Tab/Esc) ·
empty (плейсхолдер «Колонка N» приглушён) · vertical (полный текст в подсказке) ·
drop-refused («Заголовок не принимает объекты»).

## Поведение
- Клик — выбрать; двойной клик / Enter / F2 — править; Enter — готово; Tab — следующий; Esc — отмена.
- Клик по выбранному заголовку или клавиша меню открывает `AxisMenu`.
- Граница между заголовками несёт тихий «+» вставки (как продолжение у края, ADR-195).

## A11y
- В DOM-зеркале таблицы — `columnheader` / `rowheader`; пустой — «Без названия».
