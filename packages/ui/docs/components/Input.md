# Input

Текстовое поле с подписью, подсказкой, ошибкой, префиксом/суффиксом; text, password, search.

## Когда
- Любой ввод одной строки. Подпись (`label`) сверху всегда, плейсхолдер — только пример значения, не подпись.

## Состояния
default · hover · focus-visible · disabled · read-only (пунктир, фон `bg-app`) · error (рамка `danger` + текст ошибки с иконкой, `role="alert"`) · success.

## Потребитель передаёт
- `label`, `value`/`onChange`, `hint`, `error` (что случилось + что сделать), `success`, `prefix`/`suffix` (единицы: «$», «токенов»), `size`.

## Нельзя
- Ошибка без текста — только красной рамкой.
- «Ошибка 500»: пишите «Бюджет должен быть не больше 20 $ — это лимит организации».
