# Selection

Выделение на холсте: маркиза (заливка 8 % + обводка), рамка с 8 ручками и озвучиваемый счётчик.

## Правила
- Маркиза — `selection-fill` + 1 px `selection-stroke`; рамка выделения — 1.5 px, ручки `handle` (8 px) с зоной захвата `handle-hit` (12 px).
- Направляющие выравнивания — 1 px `selection-stroke` с opacity 0.4. Поворот в v1 не показываем.
- Счётчик «Выбрано 3 объекта» уходит в `aria-live`.

## Состояния
default · marquee. Остальные не применимы: выделение — объект холста. Ручки (`Handles`) — вспомогательный элемент `Selection` и `Frame`, отдельного API у них нет.

## Потребитель передаёт
- `width`, `height`, `count`, `marquee`.
