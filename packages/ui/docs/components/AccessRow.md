# AccessRow

Строка доступа в Share: кто + роль + источник роли + действия (П7).

## Правила (паттерн 1)
- Под именем всегда **источник** роли словами: «Через команду PM», «Выдано напрямую · Александр Костылев», «Владелец доски». Это главное отличие от референса — участник видит, почему у него такая роль.
- Если роль не меняется из этой строки (наследуется или это владелец) — `locked`, роль текстом.
- Удаление доступа — пункт «Нет доступа» в списке ролей (`removable`), с подтверждением, если вы теряете доступ сами.
- Агенты отличаются формой аватара.

## Состояния
default · disabled (селектор роли) · read-only (`locked`: роль показана текстом) · revoked (вариант строки). hover, active, focus-visible — не применимы: наведение и фокус принадлежат нативному `select`; loading, error, selected — не применимы.

## Потребитель передаёт
- `name`, `source`, `role`, `roles`, `onRoleChange`, `you`, `agent`, `locked`, `removable`, `revoked`.
