# EdgeContinue

Тихий «+» на краю выделенного объекта: продолжить мысль новым объектом со связью.

> **Статус:** спроектирован, в коде нет. Макеты — холст «REMO — визуальные направления»; решение — ADR-195; экраны P4, P5, R5–R7.

## Анатомия
Круг 24 px на стороне с портом: полупрозрачная заливка панели, тонкий контур, `plus` 16; зона
попадания 44 px. Активный (наведение/фокус) — непрозрачный, контур 1.5 чернилами. Превью рисуется
слоем поверх холста: пунктирный призрак и пунктирная связь, либо подсвеченная цель.

## Состояния
idle · active · preview-free · preview-occupied (с «Связать с существующим» / «Создать новый») ·
already-linked · locked-target · stale · touch-armed · keyboard-focused.

## Поведение
- Виден, пока объект выделен и редактируем; скрыт при вводе, перетаскивании, без права правки.
- Клик / Enter = клик по порту ADR-137; касание — два тапа; Shift никогда не единственный путь.

## A11y
- Настоящая кнопка (DOM поверх холста) с именем «Продолжить справа» и т. п.; `aria-live` объявляет действие превью.
