# Skeleton

Заглушка на месте ещё не загруженного содержимого: та же геометрия, что у реального блока, чтобы не было скачка вёрстки.

## Когда
- Загрузка панели, списка, журнала. Если данных нет дольше 300 мс — показываем `Skeleton`, не `Spinner` на весь экран.
- Не для действий: кнопка в загрузке — `Button loading`, не скелетон.

## Анатомия
Прямоугольник `bg-hover`, радиус `radius-sm`; ширина и высота — из реального содержимого; `round` — для аватаров.

## Состояния
loading. Остальные не применимы: скелетон не интерактивен и не получает фокус.

## Потребитель передаёт
- `width`, `height`, `round`.

## A11y
- `aria-hidden="true"`; статус загрузки объявляет соседний `role="status"` или `Spinner` с `label`.

## Нельзя
- Анимировать ярче, чем `prefers-reduced-motion` разрешает; длительность — токены движения.
- Показывать скелетон дольше, чем нужно: мигающая заглушка хуже пустого места.
