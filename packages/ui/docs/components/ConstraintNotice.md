# ConstraintNotice

Одно сообщение об ограничении — разные причины: право, квота, тариф, политика, техника,
истёкшее приглашение.

> **Статус:** спроектирован, в коде нет. Макеты — холст «REMO — визуальные направления»; решение — макет P12; квоты и тарифы в продукте пока нет — компонент готовит место.

## Анатомия
Иконка (`info` / `alert` / `error`), причина одним предложением 600, следующий шаг `caption`,
до двух действий. Рамка: `border-subtle` (info), `border-strong` (warn), `danger` (error); `radius-xl`.

## Состояния
role · quota · plan · policy · technical · expired-invite · resolved.

## A11y
- `role="alert"` для блокирующего (квота, техника, приглашение), `role="status"` для информационного.

## Нельзя
- Один замок «Недоступно» на все причины; оплата как решение проблемы прав; терять введённые данные.
