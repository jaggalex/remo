# Badge

Статус, чип и счётчик в форме pill; тон означает состояние, не декор.

## Когда
- Статус строки (журнал, задача агента), роль, тег, счётчик.
- Тон: `neutral`, `accent` (выбранное/новое), `success`, `warning`, `danger`, `info`. Каждый тон всегда со словом, а для success/danger — ещё и с иконкой.

## Состояния
default · count (счётчик) · removable (кнопка удаления с собственным `focus-visible`). hover, active, disabled, loading, error, read-only, selected — не применимы: бейдж не интерактивен.

## Потребитель передаёт
- `children` (1–2 слова), `tone`, `icon`, `count` (табличные цифры), `onRemove` — для удаляемого чипа.

## Нельзя
- Красить всю строку таблицы в цвет статуса — только бейдж.
