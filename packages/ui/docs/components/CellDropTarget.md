# CellDropTarget

Подсветка ячейки при переносе одного или нескольких объектов.

> **Статус:** в коде (E6.6). Макеты — холст «REMO — визуальные направления»; решение — ADR-196; экраны T8, T12.

## Анатомия
Заливка `selection-fill`-тона и кольцо 2 px `border-focus` по ячейке под указателем; подсказка
«Отпустите — встанут в «колонка × строка», расстановка сохранится»; на старых местах — пунктирные следы.

## Состояния
idle · target · refuse-header (подсказка «Заголовок не принимает объекты», кольцо не рисуется) ·
conflict (объект заблокирован — причина словами).

## Поведение
- Выделение из одной или нескольких ячеек переносится целиком, взаимная расстановка сохраняется,
  ячейка растёт при необходимости; связи следуют.
- Альтернатива без мыши — «Переместить в ячейку…».
