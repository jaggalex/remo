# StartChoice

Выбор, как начать новую комнату: две равные карточки «Пустая комната» и «С примером».

> **Статус:** в коде (`apps/web/src/NewBoardDialog.tsx`). Решение — ADR-197; экраны P2, R2.

## Анатомия
`fieldset` с подписью «Как начать»; две карточки в сетке 1fr 1fr: заголовок `type-label` 600,
пояснение `type-caption` `text-secondary`, `bg-panel`, `border-subtle`, `radius-md`, отступ
`space-3`. Выбранная — контур 2 px `border-focus` (форма, не только цвет). Под «С примером» —
список примеров `Select`.

## Состояния
default · hover · selected · focus-visible (кольцо) · disabled — не применимо.

## Поведение
- По умолчанию «Пустая комната». «С примером» выбирает первый пример и показывает список.

## A11y
- Каждая карточка — подпись к радиокнопке, растянутой на всю карточку: одна зона клика,
  стрелки переключают выбор, имя радио — заголовок и пояснение.
