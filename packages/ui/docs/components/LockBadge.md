# LockBadge

Бейдж «Заблокировал …» на объекте холста: кто держит блокировку, `role="status"`.

## Когда
- Объект заблокирован другим участником или вами; показывается поверх стикера/фрейма.
- Если блокировка ваша — «Заблокировано вами», с действием «Разблокировать» рядом.

## Анатомия
Иконка `lock` 12 + имя `caption`; фон `bg-raised`, граница `border-subtle`, радиус `radius-pill`.

## Состояния
locked. Остальные не применимы: бейдж только читается.

## Потребитель передаёт
- `by` — имя человека; без него — «Заблокировано».

## A11y
- `role="status"`; имя — текстом, не только иконкой.

## Нельзя
- Прятать блокировку до попытки редактирования: состояние видно всегда (П4).
- Писать «Ошибка»: блокировка — не ошибка, а состояние с причиной.
