# ConfirmDialog

Подтверждение опасного действия с числом затронутых объектов и последствиями.

## Правила
- Заголовок и кнопка называют действие и число: «Удалить 12 объектов?» / «Удалить 12 объектов» (плюрализация через `Intl.PluralRules`).
- Тело говорит, что произойдёт с остальным: «Содержимое фрейма останется на доске» (ADR-070), «Вы потеряете доступ к доске».
- Где возможно — вместо подтверждения undo в тосте (паттерн 6).

## Состояния
default · loading (кнопка подтверждения). hover, active, focus-visible — у кнопок внутри; error, read-only, selected — не применимы.

## Потребитель передаёт
- `count`, `forms` (`['объект','объекта','объектов']`), `verb`, `children` (последствия), `onConfirm`, `onCancel`, `loading`, `tone="accent"` для не-деструктивных.
