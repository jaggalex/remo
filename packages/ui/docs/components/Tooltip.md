# Tooltip

Подсказка на hover/focus: короткое название действия и его шорткат.

## Когда
- У каждой IconButton и инструмента тулбара. Обрезанные имена людей и досок — полный текст в тултипе.

## Состояния
default · open. Остальные не применимы: тултип не получает фокус, триггер — родитель.

## Потребитель передаёт
- Один фокусируемый `children`, `label`, `shortcut` (`["⌘", "Z"]`), `side` (`bottom` | `top` | `right`), `align` (`center` | `end`): `end` выравнивает подсказку по правому краю триггера — для элементов у правого края окна.

## Нельзя
- Прятать в тултип информацию, нужную для решения (права, последствия) — она должна быть в тексте.
