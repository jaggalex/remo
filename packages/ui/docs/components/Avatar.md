# Avatar

Инициалы участника на его presence-цвете; AvatarStack для presence в топбаре; агент — квадратный с иконкой.

## Когда
- Строка доступа, автор комментария, presence в TopBar (AvatarStack, до 4 + «+N»).
- Агент всегда отличается формой (квадрат + иконка `agent`), а не только цветом.

## Состояния
default. Остальные восемь не применимы: аватар статичен.

## Потребитель передаёт
- `name` (цвет выбирается детерминированно из `presence-1…6`, можно задать `color`), `size="sm"`, `agent`.
