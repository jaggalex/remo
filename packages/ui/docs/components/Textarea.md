# Textarea

Многострочное поле: задача агента, комментарий, описание. Подпись сверху, ошибка с `role="alert"`.

## Когда
- Текст длиннее одной строки; для короткого значения — `Input`.
- Высота — `rows`, растягивается пользователем по вертикали; кегль не уменьшается.

## Анатомия
Контейнер `rm-input rm-textarea`, подпись `label`, сообщение (`error`/`success`/`hint`), `textarea` с автопереносом.

## Состояния
default · hover · focus-visible · disabled · error · read-only. active, loading, selected — не применимы.

## Потребитель передаёт
- `label`, `value`/`onChange`, `rows`, `hint`, `error` (что случилось + что сделать), `success`, `readOnly`.

## A11y
- Подпись связана через `htmlFor`; ошибка — `aria-describedby` и `aria-invalid`; `role="alert"` только на тексте ошибки.

## Нельзя
- Ошибка без текста — только красной рамкой.
- Ограничивать ввод молча: лимит показывается сообщением «Достигнут лимит».
