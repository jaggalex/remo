# Minimap

Мини-карта холста: область с содержимым и прямоугольник вьюпорта, без миниатюр объектов.

## Правила
- Показывает только границы содержимого (`bg-canvas`) и видимую область (`selection-stroke` + `selection-fill`) — без миниатюр, чтобы не тормозить на 1000+ объектах.
- Клик/перетаскивание по карте двигает вьюпорт без анимации. Парит в правом нижнем углу рядом с ZoomControls.

## Состояния
default. Остальные не применимы: мини-карта — навигация, клики обрабатывает холст.

## Потребитель передаёт
- `width`, `height`, `content` и `viewport` — доли `{x, y, w, h}` от 0 до 1.
