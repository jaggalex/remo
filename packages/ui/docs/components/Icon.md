# Icon

Штриховая иконка 16/20 px из минимального набора REMO; цвет — currentColor.

## Когда
- Внутри Button, IconButton, Menu, статусов. Размер `icon-sm` (16) в компактных контролах, `icon-md` (20) в тулбаре.
- Иконка без подписи — только в IconButton с `label`; в критичных действиях (удалить, отозвать доступ) подпись обязательна.

## Состояния
default. Остальные не применимы: иконка статична; hover и фокус принадлежат родительскому контролу.

## Потребитель передаёт
- `name` — одно из имён набора (`ICON_NAMES`), `size`, опционально `label` (тогда иконка читается скринридером, иначе `aria-hidden`).

## Нельзя
- Красить иконку отдельным цветом «для красоты»: она наследует цвет текста.
- Добавлять заливки и двухцветные иконки — набор только штриховой.
