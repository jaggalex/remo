# Spinner

Индикатор загрузки внутри кнопки и Skeleton для заглушек контента.

## Когда
- Spinner — только внутри Button (`loading`) или в теле панели, пока грузятся данные. В статусе синхронизации спиннер **не** используем — там слова (паттерн 4).
- Skeleton — заглушка строк таблицы, списка, инспектора, пока нет данных.

## Состояния
loading. Остальные не применимы.

## Потребитель передаёт
- Spinner: `size="sm"`, `label` если спиннер — единственный носитель состояния.
- Skeleton: `width`, `height`, `round`.

## Нельзя
- Показывать спиннер дольше 10 с без текста о том, что происходит.
