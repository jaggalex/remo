# AvatarStack

Присутствие в топбаре: до `max` лиц и «+N».

## Когда
- В `TopBar` и в шапке доски; порядок — порядок подключения.
- Для одного человека — `Avatar`, не стек.

## Анатомия
Круги 20 px (`Avatar size="sm"`) с наложением 6 px, цвет — `presence-N` по индексу; «+N» — `bg-hover`.

## Состояния
default. Остальные не применимы: стек статичен; наведение раскрывает полный список (этап 1.5).

## Потребитель передаёт
- `names`, `max` (по умолчанию 4).

## A11y
- Контейнер с `aria-label` «На доске: 7 участников»; лица — `role="img"` с именем.

## Нельзя
- Показывать больше 4 лиц: топбар теряет название доски.
- Сортировать по «активности»: порядок подключения предсказуем.
