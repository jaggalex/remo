# AxisResizeHandle

Ручка размера на границе заголовка: ширина колонки — правая граница, высота строки — нижняя.

> **Статус:** спроектирован, в коде нет. Макеты — холст «REMO — визуальные направления»; решение — ADR-196; экран T13.

## Анатомия
Полоса 4 px `border-focus` во время жеста, зона попадания 24 px (на касании 44); курсор
`col-resize` / `row-resize`; рядом подсказка со значением в px.

## Состояния
idle (не видна) · hover · dragging (значение) · touch.

## Поведение
- Один жест — один undo; жест переводит ось в «Вручную».
- На дальнем масштабе ручки скрыты; размер остаётся в `TablePanel` / `AxisSizeMenu`.
