# AxisResizeHandle

Ручка размера на границе заголовка: ширина колонки — правая граница, высота строки — нижняя.

> **Статус:** в коде (`apps/web/src/TableAxisControls.tsx`). Макеты — холст «REMO — визуальные направления»; решение — ADR-196, ADR-201; экран T13.

## Анатомия
Невидимая полоса 8 px на границе заголовка, курсор `col-resize` / `row-resize`. При наведении и
фокусе — линия 2 px `border-focus`. Во время жеста — пунктирная направляющая через всю таблицу
(`border-focus`) и плашка значения «320 px» (`bg-inverse`, `text-inverse`, `type-caption`).

## Состояния
idle (не видна) · hover · focus-visible (линия + кольцо) · dragging (направляющая и значение) ·
read-only — не применимо: ручки скрыты без права правки и у заблокированного раздела.

## Поведение
- Перетаскивание задаёт ручной размер в px; один жест — один undo.
- Двойной клик или Delete / Backspace на сфокусированной ручке — обратно «Авто».
- Ручной размер — нижняя граница: содержимое всё равно помещается, объекты не сжимаются.
- Значение ограничено минимумом оси (колонка 120, строка 72) и 2 400 px.

## A11y
- `role="separator"`, `aria-orientation`, `aria-valuenow` (текущий размер), имя «Ширина колонки «…»».
- ← / → (колонка) или ↑ / ↓ (строка) — шаг 8 px, с Shift — 40 px.
