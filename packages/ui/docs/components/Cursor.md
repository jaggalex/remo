# Cursor

Presence: курсор участника с именем на плашке его цвета, затухание 2 с, «печатает», «следит за вами» и рамка «Слежу за …».

## Правила
- 6 фиксированных цветов `presence-1…6` (в тёмной теме светлее), имя — `text-on-presence` ≥ 4.5:1.
- Состояния: `moving`, `idle` (затухает за 2 с), `typing`, `following` (следит за вами).
- Режим следования — FollowIndicator: рамка 2 px цвета участника по краю вьюпорта + подпись «Слежу за Алекс» с кнопкой «Остановить».
- Курсоры не анимируются при pan/zoom.

## Состояния
moving · idle · typing · following. Остальные не применимы: курсор — отображение присутствия.

## Потребитель передаёт
- Cursor: `name`, `color`, `state`. FollowIndicator: `name`, `color`, `onStop`.
