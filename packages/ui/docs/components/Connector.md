# Connector

Связь между объектами: маршрут `routing` (`straight | elbow | curved`, ADR-077) × наконечник `head` (`none | arrow | block`) — свойства одного объекта; состояния `default`, `hover`, `selected`, `editing-label`, `pending`; порты фигуры.

## Правила
- Конец связи — ссылка на объект и порт, а не координата. Связь **удаляется вместе с объектом-концом** (ADR-077): состояния «разорванная связь» нет; диалог удаления считает и связи, undo возвращает объект вместе с ними.
- Четыре типа ТЗ §5.1 — сочетания: `line` = straight + none, `arrow` = straight + arrow, `elbow` = elbow + arrow, `block` = straight + block.
- Выбранная связь: полые точки на концах и на закреплённых (`rigid`) точках, залитая точка в середине каждого сегмента (потянуть — добавить точку). Размер точек постоянен в экранных пикселях при любом зуме. В `curved` закреплённые точки — опоры, вокруг которых изгибается дуга.
- На доске связь рисует Canvas 2D painter по тем же токенам (`readCanvasTokens()`); DOM-версия — для каталога и оверлеев (ADR-078).
- `pending` — превью от источника к курсору в режиме создания.
- Подпись связи — на фоне холста, `caption`.

## Порты (Ports)
- 8 точек по периметру (4 стороны + 4 угла), появляются на hover, `hot` под курсором увеличивается, «прилипание» в радиусе `handle-hit` (12 px), `connected` — залитые.
- С клавиатуры: `Tab` внутри выбранного объекта обходит порты, `Enter` начинает связь, `Esc` отменяет.

## Состояния
default · hover · selected · editing-label · pending. disabled, loading, error, read-only, selected — не применимы. Состояния «разорванная связь» нет: связь удаляется вместе с объектом (ADR-077).

## Потребитель передаёт
- Connector: `routing`, `head`, `state`, `from`, `to`, `waypoints` (`{x, y, rigid}`), `label`, `width`, `height`. Ports: `width`, `height`, `hot`, `connected`, `visible`, `label`.
