# Kbd

Горячая клавиша в меню и тултипах; моноширинный стиль `kbd`.

## Когда
- В пунктах Menu (`shortcut`) и в Tooltip инструментов. Каждое действие с шорткатом показывает его хотя бы в одном месте.

## Состояния
default. Остальные не применимы.

## Потребитель передаёт
- `keys` — массив клавиш (`['⌘','Shift','L']`) или строку через пробел в `children`.

## Нельзя
- Писать клавиши в подписи кнопки: для этого есть Kbd.
