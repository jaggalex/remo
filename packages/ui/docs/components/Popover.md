# Popover

Немодальное всплывающее окно у элемента: пикер, короткая настройка, подтверждение «на месте».

## Когда
- Пикер цвета, настройка таймера, короткая форма из 1–3 полей, привязанная к кнопке. Больше — Dialog.
- Немодальный: фокус уходит внутрь, `Esc` закрывает и возвращает фокус на кнопку-источник; клик снаружи закрывает.

## Правила
- `bg-raised`, волосяная линия 1 px `border-subtle`, `radius-xl`, стрелка к источнику; тени нет (`shadow-pop` = `none`, правило E2, ADR-181); слой `z-popover`.
- Одно основное действие в футере, если оно есть (П2).

## Состояния
default · open. hover, active, focus-visible — внутри; disabled, loading, error, read-only, selected — не применимы.

## Потребитель передаёт
- `title` или `label`, `side` (`bottom` | `top` | `right`), `width`, `children`, `footer`, `onClose`.
