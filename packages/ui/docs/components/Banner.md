# Banner

Встроенное сообщение в потоке диалога или панели: предупреждение о последствиях, офлайн, read-only.

## Когда
- Состояние, которое длится: «Нет сети», «Доска только для просмотра», «Ссылка без пароля».
- Предупреждение о последствиях внутри диалога: «Вы и ваша команда потеряете доступ» (П6).

## Состояния
info · warning · danger · success · dismissable · with action. Девять интерактивных состояний не применимы: баннер — сообщение, действия внутри — `Button`/`IconButton`.

## Потребитель передаёт
- `tone` (`info` | `warning` | `danger` | `success`), `title`, `children`, `action`, `onClose`.

## Нельзя
- Заливать цветом всю панель — баннер одной строкой в мягком тоне.
