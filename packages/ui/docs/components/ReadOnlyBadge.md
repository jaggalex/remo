# ReadOnlyBadge

Статус «Только просмотр» в топбаре и у края доски: слово + иконка глаза, `aria-live`.

## Когда
- Доступ отозван, доска открыта по ссылке в режиме просмотра, объект заблокирован другим участником.
- Всегда вместе с объяснением причины рядом (П7).

## Анатомия
Иконка `eye` 16 + подпись `label`; цвет `text-secondary`, фон `bg-hover`, радиус `radius-pill`.

## Состояния
read-only. Остальные не применимы: бейдж только читается.

## Потребитель передаёт
- `children` — причина словами («Доступ отозван», «Только просмотр»); по умолчанию — общий текст из i18n.

## A11y
- `role="status"`, `aria-live="polite"`; причина — текстом, не только иконкой.

## Нельзя
- Показывать «только просмотр» без причины и без выхода: человек должен понимать, что делать.
- Использовать как единственный признак: блокировка ввода ещё и не даёт писать.
