# Link

Текстовая ссылка цвета `text-accent` для навигации и вторичных переходов внутри текста.

## Когда
- Переход к другому экрану или документу («Открыть журнал», «Настройки организации»). Действие, меняющее данные, — Button.

## Состояния
default · hover · active · focus-visible · visited. disabled, loading, error, read-only, selected — не применимы: для недоступного действия — `Button disabled`.

## Потребитель передаёт
- `href`, `children`. Внешняя ссылка — `target="_blank" rel="noopener"` и это видно в тексте.

## Нельзя
- Убирать подчёркивание: цвет не единственный признак ссылки.
