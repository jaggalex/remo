# ZoomControls

Зум-контролы доски: −, значение, +, «вписать». У каждой кнопки — подсказка с именем (ADR-232).

## Когда
- Всегда в левом нижнем углу доски.
- Значение — кнопка сброса к 100 %, только если передан `onReset`; без него это надпись, а не кнопка, которая ничего не делает.
- Зум и пан не анимируются.

## Анатомия
Пилюля `bg-raised`, волосяная линия 1 px `border-subtle`, `radius-pill`, без тени (правило E2, ADR-181); `IconButton` 28, значение — `rm-num` 44 px, разделитель и кнопка fit.

## Состояния
default · hover · focus-visible · disabled (кнопка на пределе зума). loading, error, read-only, selected — не применимы.

## Потребитель передаёт
- `zoom`, `onIn`, `onOut`, `onFit`; необязательные `onReset` и `fitHint` — подсказка кнопки «вписать», когда она вписывает не только всё (например, выделение).

## A11y
- `role="group"` с подписью «Масштаб»; у значения — `aria-label` «Масштаб 84 %»; клавиши `+`/`−` работают и без фокуса на панели (этап 1.6).

## Нельзя
- Прятать значение: человек должен видеть текущий масштаб.
- Округлять процент до «красивых» чисел в ущерб точности.
