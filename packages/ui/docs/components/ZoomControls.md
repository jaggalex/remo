# ZoomControls

Зум-контролы доски: −, значение (сброс к 100 %), +, «показать всё».

## Когда
- Всегда в левом нижнем углу доски; значение кликабельно для сброса.
- Зум и пан не анимируются.

## Анатомия
Панель `bg-raised`, `radius-md`, `shadow-bar`; `IconButton` 28, значение — `rm-num` 44 px, разделитель и кнопка fit.

## Состояния
default · hover · focus-visible · disabled (кнопка на пределе зума). loading, error, read-only, selected — не применимы.

## Потребитель передаёт
- `zoom`, `onIn`, `onOut`, `onReset`, `onFit`.

## A11y
- `role="group"` с подписью «Масштаб»; у значения — `aria-label` «Масштаб 84 %»; клавиши `+`/`−` работают и без фокуса на панели (этап 1.6).

## Нельзя
- Прятать значение: человек должен видеть текущий масштаб.
- Округлять процент до «красивых» чисел в ущерб точности.
