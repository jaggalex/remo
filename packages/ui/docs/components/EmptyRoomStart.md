# EmptyRoomStart

Старт пустой комнаты: первый объект за одно решение.

> **Статус:** спроектирован, в коде нет. Макеты — холст «REMO — визуальные направления»; решение — ADR-197 (ещё не написан); экран P3, R3.

## Анатомия
По центру холста: заголовок «Начните с заметки или фигуры», строка «Их можно соединить линией.»;
две равные кнопки `out` 48 — «Заметка», «Фигура»; ниже `ghost` «Текст» и ссылка «Или посмотрите
пример →». Единственная ink-кнопка экрана остаётся «Поделиться».

## Поведение
- Кнопка создаёт объект в центре вьюпорта и сразу открывает ввод; Esc заканчивает.
- Пропадает, как только в комнате есть объект; в режиме только чтения не показывается.
- Пока открыт план агента — скрыт (ADR-188).

## Нельзя
- Отправлять в «меню Ещё» за шаблоном; делать шаблон primary.
