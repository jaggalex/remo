# SeedPreview

Выбор раскладки при первой оси: превью на холсте и короткое решение рядом.

> **Статус:** спроектирован, в коде нет. Макеты — холст «REMO — визуальные направления»; решение — ADR-196; экран T4.

## Анатомия
`Panel` у раздела: «Как разложить материал?» — радио «Разложить по текущему расположению» /
«Оставить всё в первой ячейке», подсказка, «Отмена» и «Применить». На 1024 — нижним листом, чтобы
не закрывать превью.

## Поведение
- Превью совпадает с результатом; плотный материал — по умолчанию «Оставить».
- Дефолт — открытый вопрос (гипотеза H4 шести сессий); до ответа — «Оставить всё в первой ячейке».
- Один undo возвращает исходное расположение.
