# FloatingBar

Панель действий над выделением: счётчик, не более 6 действий и «⋯».

## Правила (паттерн 3)
- Не больше **6** действий + `⋯` — иначе на 1280 px панель перекрывает выделение. Лишнее уходит в меню «⋯» (компонент предупреждает в консоли).
- Над объектом шириной 120 px выходит за его края не больше чем на 40 px с каждой стороны.
- Цвет — swatch-кнопкой с подписью в aria-label.

## Состояния
default · selected · hover · focus-visible (у действий) · disabled (действие). loading, error, read-only — не применимы. Больше 6 действий — ошибка разработчика (`console.warn`).

## Потребитель передаёт
- `count`, `actions`: `{icon, label, onClick, selected?, danger?}` | `{swatch:'sticker-yellow', label}`; `onMore`.
