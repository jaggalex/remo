# Тексты и глоссарий

## Тон

Нейтральный, без оценок («хорошо», «плохо») и без обвинений («вы сделали»). Без «успешно», «просто» и восклицательных знаков в системных сообщениях. Обращение на «вы» со строчной.

## Правила

- **Кнопки** — глагол в инфинитиве, без «пожалуйста»: «Удалить», «Скопировать ссылку», «Запустить». Действие, ведущее к подтверждению, — с многоточием в меню: «Удалить…».
- **Ошибка = что случилось + что сделать:** «Нет связи. Правки сохранены локально — они отправятся, когда соединение вернётся». Не «Ошибка 500».
- **Права — с источником:** «Редактор через команду PM», «Заблокировал Алекс», «Ссылка выключена — открыть доску могут только участники».
- **Числа с существительными** — через плюрализацию: «1 объект», «3 объекта», «12 объектов». Даты — `Intl.DateTimeFormat` («26.10.2026, 14:05»).
- **Имена людей и досок** обрезаются по ellipsis с тултипом полного текста; в диалогах — перенос на две строки, дальше ellipsis.
- **Заголовки:** H2 — разделы диалога, H3 — группы внутри; не больше двух уровней на экран.

## Примеры

| Вместо | Пишем |
|---|---|
| Доска успешно сохранена! | Сохранено |
| Ошибка доступа | Доступ отозван. Настройки доступа к доске изменились — попросите владельца выдать доступ снова |
| Вы удалили объекты | Удалено 12 объектов · Отменить |
| Пожалуйста, введите бюджет | Бюджет · не больше 20 $ — это лимит организации |
