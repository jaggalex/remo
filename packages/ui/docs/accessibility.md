# Доступность и клавиатура

## Общие правила

- Всё достижимо с клавиатуры, порядок логичный. `Esc` закрывает верхний слой, фокус возвращается туда, откуда пришёл. Фокус-ловушка — только в модальных диалогах.
- `:focus-visible` — 2 px `border-focus` + offset 2 px; кольцо ≥ 3:1 на всех поверхностях. Никогда не убираем без замены.
- `aria-live="polite"` — для статусов (сохранено, офлайн, отозвано, «выбрано 3 объекта»); `role="alert"` — для ошибок.
- Иконка без текста → `aria-label`; декоративная → `aria-hidden`.
- Контраст проверяется в CI на токенах (`pnpm ds:contrast`), а не глазами: все пары `text-*` на `bg-*` ≥ 4.5:1 в обеих темах.
- Кнопка не переносит текст; подпись ≤ `label-max` (240 px). Не влезает — сокращаем текст, а не компонент. Автотест каталога: `scrollWidth <= clientWidth` для всех кнопок в RU и EN.

## Клавиатурная модель холста

| Действие | Клавиши | Поведение |
|---|---|---|
| Войти в холст | `Tab` из топбара | фокус на первом объекте в порядке создания |
| Обход объектов | `Tab` / `Shift+Tab` | по порядку создания; сфокусированный объект выделен |
| Выделить несколько | `Shift` + стрелки обхода | мультивыделение без мыши |
| Переместить | стрелки (1 px), `Shift`+стрелки (10 px) | без изменения порядка |
| Изменить размер | `Alt`+стрелки | 1 px за нажатие |
| Войти в текст | `Enter` | каретка в конце; `Esc` — назад к объекту |
| Обход якорей | `Tab` внутри выбранного объекта | 8 портов; `Enter` — начать связь, `Esc` — отменить |
| Контекстное меню | `Shift+F10` | то же меню, что правый клик |
| Выйти из холста | `Esc` дважды | фокус в топбар, туда, откуда пришли |
| Статус | `aria-live` | «Выбрано 3 объекта», «Перемещено на 10 px» |

## Локализация

- RU — основной, EN — обязательный второй. Все строки — в `apps/web/src/i18n.tsx`, один механизм: `@remo/ui` объявляет только ключи (`UiKey`), слова лежат там же под `ds.*`, приложение передаёт адаптер `useI18n().ui` в `<UiStringsProvider>`. Ключ без перевода валит `tsc`.
- Не склеиваем строки: `{n} объектов` → плюрализация (`count()` из `i18n.tsx`).
- Не вмещаем смысл в иконку. Оставляем 30 % запаса по ширине под EN.
- Даты и числа — через `Intl` (`format.ts`); время — 24 ч.
