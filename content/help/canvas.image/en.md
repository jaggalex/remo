## Result

An image object appears in the room: every participant sees it, and it can be moved, resized with its proportions kept, made a slide and exported with the room.

## Add an image

- **With the button.** Click **Image** on the toolbar and choose one or more files.
- **By dragging.** Drag files from Finder or Explorer to the place on the canvas where they belong. While the files are over the canvas, the **Drop to add** frame shows the number of files.
- **By pasting.** Copy a picture or a screenshot and press `⌘V` / `Ctrl+V`. A picture in the clipboard wins over text: the image is pasted.

The object appears only after the upload finishes. Until then only you see the placeholder with progress; other participants see the finished picture, never a half-uploaded object. If a file is refused, the placeholder explains why and offers **Retry** or **Remove**.

PNG, JPEG, WebP, GIF and AVIF are accepted. SVG and HEIC are not supported in this version. A file may be up to 20 MB, and a room holds up to 500 images. A GIF shows its first frame.

## Replace and describe

1. Select the image. On the object bar click **Replace** and choose a new file: the object stays where it is and its size follows the new picture.
2. Click **Description** and write what the picture shows. Screen readers read it, the lightbox shows it and the export carries it. A good description is "Sales funnel: three stages, 12 % conversion", not "image".
3. **Natural size** in the **More** menu returns the object to the file's own size.

## View and download

- Double-click an image to open the lightbox. The wheel zooms, dragging moves the picture, a double click fits it again and `Esc` closes it.
- **Download original** in the **More** menu, or the button in the lightbox, returns the untouched file. It needs the export grant (`board.export`).
- The canvas shows a smaller copy sized for the screen; the original is stored separately.

## Check

- After the upload the image stands where you dropped it, or in the centre of the screen when you used the button.
- A second participant sees the picture after the upload completes.
- Resizing by a corner keeps the proportions.
- `⌘Z` / `Ctrl+Z` after a delete brings the object back with its picture.
- A PNG export contains the picture, not a placeholder.

## If it did not work

- **"The file is larger than 20 MB".** Make the file smaller or save it at a lower quality.
- **"This format is not supported".** Save the picture as PNG, JPEG or WebP.
- **"The storage is full".** Free space in the organisation or change the plan. The organisation's **Storage** tab shows what is used.
- **"The room already has 500 images".** Delete the pictures you no longer need or use a separate room.
- **"Image unavailable".** The file was removed by the collector or did not come back from a backup without images. Upload it again; the object itself can stay.
