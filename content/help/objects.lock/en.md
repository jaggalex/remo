## Result

A locked object cannot be moved, edited or deleted, but it can still be selected. The lock records its author: only the author or a board manager can release it.

## Steps

1. Select the object and click **Lock** in the menu or press `⌘⇧L` / `Ctrl+Shift+L`.
2. To release it, select the object and click **Unlock**.
3. If somebody else locked it, the interface names them and points you to the author or a board manager.
4. **Unlock everything you can** in the menu releases your locks; a board manager releases every lock.

## Check

- A second editor cannot move, edit or delete the object.
- The author releases their lock; a board manager releases somebody else's.
- A copy or duplicate of a locked object appears unlocked.
- The object's info shows who locked it.

## Limits

- A lock is coordination, not access control: it stops accidental edits in the interface, not a direct document write.
- An old lock with no recorded author can be released by any editor, until it is toggled once.
- A lock on a frame does not lock its contents; to protect a group, select it and lock the members.
