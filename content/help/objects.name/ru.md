## Результат

У объекта есть необязательное **Имя** для поиска и презентации и постоянный **ID** для ссылок и команд. Имя не рисуется на холсте; ID не меняется.

## Шаги

1. Выделите объект на комнате.
2. В инспекторе заполните поле **Имя** и нажмите Enter или кликните вне поля. Пустое значение убирает имя.
3. Рядом показан **ID** только для чтения. Нажмите **Скопировать ID**, чтобы вставить его в ссылку, команду или сообщение об ошибке.

## Проверка

- Имя видно в списке объектов презентации и находится поиском.
- Имя не появилось на холсте и не изменило текст объекта.
- ID остался прежним после переименования и перезагрузки.

## Ограничения

- Имя не обязано быть уникальным: два объекта могут называться одинаково.
- ID изменить нельзя; это стабильная идентичность объекта.
- Пустое имя означает «без имени»; подпись в презентации берётся из заголовка, текста или ID.
