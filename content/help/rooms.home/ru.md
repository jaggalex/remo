## Результат

Вы видите домашнюю страницу организации: плитки комнат с эмодзи, названием, командой,
автором и датами. Здесь же — поиск по названию, сортировка, страницы и переключение
организации.

## Подготовка

- Вы вошли в аккаунт. У каждого аккаунта есть личная организация с бейджем **Личная**;
  в ней можно работать одному или с командой по интересам.
- Чтобы попасть сюда с комнаты, нажмите **Все комнаты** в шапке или название организации
  слева от названия комнаты.

## Шаги

1. Откройте **Все комнаты**. Результат: адрес `?org=…`, комната закрыта, показаны плитки
   выбранной организации.
2. Выберите организацию в поле **Организация**. Результат: предыдущая комната и
   организация остаются позади, список показывает комнаты новой организации.
3. Найдите комнату по названию в поле поиска. Результат: список сужается; пустой ответ
   говорит, что совпадений нет.
4. Выберите сортировку: **Обновление**, **Создание**, **Название** или **Автор**.
   Стрелка рядом меняет направление. Результат: плитки идут слева направо и сверху
   вниз в выбранном порядке.
5. Листайте страницы по 24 плитки: номера внизу и стрелки ‹ ›.
6. Нажмите на плитку, чтобы открыть комнату. Меню плитки меняет эмодзи, копирует или
   удаляет комнату, если у вас есть право.
7. Нажмите **Новая комната**, чтобы создать комнату в выбранной организации.
8. **Корзина** рядом с «Комнаты» показывает удалённые комнаты; **Восстановить** возвращает комнату в список. Восстановить может только владелец.

## Проверка

- В шапке видно название организации и бейдж **Личная** для личной.
- На плитке есть название, команда, автор `Имя @ник`, дата создания и обновления.
- Эмодзи остаётся после перезагрузки.
- Удалённая комната появляется в корзине и восстанавливается обратно.
- После смены организации открытая ранее комната больше не показана.

## Ограничения

- Иконка комнаты — один эмодзи. Картинки и загружаемые иконки появятся позже.
- Автор — создатель комнаты; передача владения не меняет автора.
- Для старых комнат дата создания восстановлена по последнему обновлению и может быть
  неточной.
- Поиск ищет по названию комнаты, а не по тексту на холсте.
