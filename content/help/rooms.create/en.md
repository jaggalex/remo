## Result

A new room is created in your organisation — in a team when one is chosen — and opened. It is either empty or contains the chosen template; the name can be changed in the header.

## Steps

1. Open **All rooms** in the header. If you belong to several organisations, choose one in the **Organisation** field — the previous room closes and the list shows the new organisation's rooms.
3. Enter a name.
4. If there are several organisations or teams, choose the right ones. Create an organisation in the account menu under **Organisation and people** with **+ New organisation**; create a team in the **Teams** block (organisation admin).
5. Choose Empty room or a template. The template arrives in the account language: Russian copy for a Russian profile, English copy for an English one.
6. Click Create.

## Check the result

- The new room opens and its id is in the address.
- The name matches the one you entered.
- If you chose a template, the room contains its objects; an empty room has none.

## Limits

- A guest cannot create a room: the button is disabled and a direct request is refused. Ask the organisation administrator.
- Creation belongs to an active organisation member. A view-only link does not grant it.
- A template can be added later from **More ▾ → Templates…**.
