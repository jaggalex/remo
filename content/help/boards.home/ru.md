## Результат

Вы видите домашнюю страницу организации: плитки досок с эмодзи, названием, командой,
автором и датами. Здесь же — поиск по названию, сортировка, страницы и переключение
организации.

## Подготовка

- Вы вошли в аккаунт. У каждого аккаунта есть личная организация с бейджем **Личная**;
  в ней можно работать одному или с командой по интересам.
- Чтобы попасть сюда с доски, нажмите **Все доски** в шапке или название организации
  слева от названия доски.

## Шаги

1. Откройте **Все доски**. Результат: адрес `?org=…`, доска закрыта, показаны плитки
   выбранной организации.
2. Выберите организацию в поле **Организация**. Результат: предыдущая доска и
   организация остаются позади, список показывает доски новой организации.
3. Найдите доску по названию в поле поиска. Результат: список сужается; пустой ответ
   говорит, что совпадений нет.
4. Выберите сортировку: **Обновление**, **Создание**, **Название** или **Автор**.
   Стрелка рядом меняет направление. Результат: плитки идут слева направо и сверху
   вниз в выбранном порядке.
5. Листайте страницы по 24 плитки: номера внизу и стрелки ‹ ›.
6. Нажмите на плитку, чтобы открыть доску. Меню плитки меняет эмодзи, копирует или
   удаляет доску, если у вас есть право.
7. Нажмите **Новая доска**, чтобы создать доску в выбранной организации.
8. **Корзина** рядом с «Доски» показывает удалённые доски; **Восстановить** возвращает доску в список. Восстановить может только владелец.

## Проверка

- В шапке видно название организации и бейдж **Личная** для личной.
- На плитке есть название, команда, автор `Имя @ник`, дата создания и обновления.
- Эмодзи остаётся после перезагрузки.
- Удалённая доска появляется в корзине и восстанавливается обратно.
- После смены организации открытая ранее доска больше не показана.

## Ограничения

- Иконка доски — один эмодзи. Картинки и загружаемые иконки появятся позже.
- Автор — создатель доски; передача владения не меняет автора.
- Для старых досок дата создания восстановлена по последнему обновлению и может быть
  неточной.
- Поиск ищет по названию доски, а не по тексту на холсте.
