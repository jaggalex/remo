## Result

The board moves to the trash and closes for everyone, including the public link. The owner can restore it from the trash; there is no automatic purge by age. A copy is a new board without a public link.

## Move to the trash

1. Open the organisation home with **All boards**.
2. Open the board tile menu and click Delete.
3. Check the object count and the link warning.
4. Confirm Move to trash.

The board closes on every path at once: page, sync, public link, export and agent tasks.

## Restore

1. On the home switch to **Trash**.
2. Click Restore on the board tile.

Only the owner can restore. The public link stays off after a restore: turn it on separately if it is needed again.

## Copy

1. Open the board tile menu and click Copy.
2. The new board opens immediately; its name ends with "(copy)".

The copy gets the content and member grants, but not the public link. It is a new board with its own access.

## If it did not work

- **No Delete action.** Only the owner can delete a board.
- **No Copy action.** Only the owner or a co-owner can copy a board.
- **No Restore action.** Only the owner can restore a board.
- **The link does not work after restore.** That is intended: turn it on again.
