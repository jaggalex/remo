## 3. Эпики

Для каждого эпика: ADR пишется/уточняется **до** кода (AGENTS.md, правило 2); каждая мутация
идёт через команду с проверкой права и аудитом; строки — в `apps/web/src/i18n` (RU+EN);
только токены `@remo/ui`; браузерный сценарий в `e2e/`; `content/help` и `guide/` — если
описывают поведение; `pnpm verify --e2e` зелёный.

### E1 · Замок на холсте (ADR-193)

- **Что:** у любого заблокированного виджета — `lock-on` 16 screen px в правом верхнем углу,
  ink 75 %; author-lock — тот же значок. Не в экспорте и не в презентации. Не кнопка.
- **Модули:** чистая функция места значка в `packages/canvas` (тест без браузера);
  отрисовка в `apps/web/src/painters.ts` → `paintOverlayLayer` (экранные пиксели, как ручки
  выделения). `LockBadge` из `@remo/ui` — DOM-бейдж «Заблокировал …» для панели объекта; это
  другой элемент, не путать.
- **Приёмка:** значок у всех типов, одинаковый на 25 % и 200 %; в PNG/PDF его нет; клик
  выбирает объект; эталон с заблокированным стикером переснят (`pnpm baselines`).

### E2 · Тема и язык (ADR-194)

- **Что:** `light | dark`, по умолчанию светлая; сохранённое `system` читается как `light` и
  перезаписывается только выбором человека. Две иконки-кнопки у правого края **каждой**
  шапки (главная — после аккаунта, комната — после «Поделиться»); из меню аккаунта сегменты
  темы и языка убираются.
- **Модули:** `apps/web/src/useTheme.ts`, `i18n.tsx`, `useAccountPreferences`,
  `topbar/AccountMenu.tsx`, шапки главной и комнаты; `apps/sync` — `PATCH /auth/preferences`
  ещё один релиз принимает `system`.
- **Приёмка:** новый аккаунт — светлая; аккаунт с `system` — светлая без записи; переключение
  одним кликом, имя кнопки называет следующее состояние; на 1024 значки на том же месте;
  справка о меню аккаунта обновлена.

### E3 · Первый вход (P1–P3; сначала ADR-197)

- **ADR-197 должен зафиксировать:** главная без директории, пока комнаты помещаются на
  страницу; новая комната — «Пустая» по умолчанию, организация и команда — только если их
  больше одной; пустая комната — «Заметка» и «Фигура» равны, «Текст» третичный, пример —
  тихая ссылка; «Свойства» у нового человека закрыты.
- **Модули:** `WorkspaceHome.tsx`, `NewBoardDialog.tsx`, `BoardOverlays.tsx` (`EmptyBoard` →
  компонент `EmptyRoomStart`), `useBoardChrome.ts` (инспектор).
- **Приёмка:** до ввода текста — 3 решения (открыть → «Заметка»/«Фигура» → печатать);
  клик создаёт объект в центре вьюпорта в режиме ввода; Esc заканчивает; текст «Выберите
  шаблон в меню Ещё» из пустой комнаты ушёл; «пример» без демо-комнаты ведёт в выбор шаблона
  (до решения о демо).

### E4 · Продолжение «+» (ADR-195)

- **Что:** у выделенной редактируемой заметки/фигуры — полупрозрачный «+» на каждой стороне с
  портом (24 визуально, 44 зона); виден без наведения, Tab + Enter; наведение/фокус рисует
  превью (призрак и пунктир) слоем поверх холста; клик = клик по порту ADR-137; в занятом
  месте — «Связать с существующим» / «Создать новый»; касание — два тапа.
- **Модули:** общая чистая функция размещения превью (её же использует команда, чтобы
  показанное = созданное) рядом с `anchorSlotDecision` в `apps/web/src/canvasGeometry.ts`;
  отрисовка — `painters.ts`; DOM-кнопки «+» для доступности — по образцу floating targets;
  `gesturePointerUp.ts`, `useBoardKeyboard.ts` (Tab сохраняет смысл).
- **Приёмка:** наведение, Esc и уход указателя не меняют документ (ни объектов, ни сетевых
  записей); создание = объект + связь = один undo; уже связанная пара — «Уже связаны», без
  второго ребра; всё доступно без hover и без Shift; «+» скрыт при вводе, перетаскивании и без
  права правки.

### E5 · «Собрать в раздел»

- **Сначала:** дописать в ADR-196 (или отдельным ADR) атомарную команду: рамка по границам
  выделения с отступом, членство одной операцией, конфликты (объект в другом разделе,
  замок, раздел в раздел) объясняются **до** выполнения.
- **Модули:** `ArrangeBar.tsx`, `useBoardCommands.ts`, `packages/doc/src/widgets.ts`
  (членство), команда в `apps/sync`.
- **Приёмка:** ID, текст, связи сохраняются; один undo возвращает исходное членство; превью
  границы до клика; конфликт с двумя честными действиями (P6).

### E6 · Раздел → таблица (ADR-196)

Большой эпик; резать на PR по слоям, каждый зелёный сам по себе.

| Срез | Что | Модули |
|---|---|---|
| 6.1 Модель | `frame.layout = {kind:"table", columns, rows}`, оси со стабильными ID, `cell` у объекта, смещение внутри ячейки, размеры `auto/manual`, необязательные фоны; отсутствие `layout` = свободно; версионный гейт для старого клиента | `packages/model` (+тест, read migration), `packages/doc` |
| 6.2 Команды | добавить в конец / вставить между / переместить / переименовать / повернуть / размер / удалить ось (с переносом в соседа или с объектами); перенести выделение в ячейку; «Убрать таблицу»; фон | `packages/doc`, команды и аудит `apps/sync` |
| 6.3 Отрисовка и попадание | сетка, шапки, фоны, «+» на границах, подсветка ячейки, отказ шапки; ручки размера | `packages/canvas` (чистая геометрия + тесты), `painters.ts` |
| 6.4 Панель раздела | `TablePanel`: вид, оси, размер, «Оформление таблицы» (свёрнуто), «Убрать таблицу», «Удалить раздел» | `apps/web` + `@remo/ui` |
| 6.5 Заголовки и меню | правка на месте (Enter/F2/Tab/Esc), `AxisMenu`, вертикальный заголовок | `apps/web` |
| 6.6 Перенос | drag одного и нескольких объектов, «Переместить в ячейку…», связи следуют | `useGestures`, `canvasGeometry` |
| 6.7 Экспорт и бэкап | PNG/PDF с сеткой и размерами; JSON с `layout`; восстановление | `exportRender.ts`, `backup*` |
| 6.8 Доступность | скрытая DOM-таблица-зеркало, клавиатурный режим, `aria-live` | `apps/web` |
| 6.9 Презентация | порядок по строкам, фокус на ячейке, следование | презентация |
| 6.10 AI-проекция | ячейки в проекции для агента | `apps/sync` projection |

- **Приёмка (минимум):** объекты и связи целы после каждого действия и после «Убрать таблицу»
  → «Таблица»; удаление оси с объектами спрашивает и по умолчанию переносит в соседа (соседа,
  которого нет, не предлагаем); в ячейке несколько объектов в свободной расстановке, перенос
  раздела их не трогает; «Авто» — по крайним объектам + отступ, пустая ось — под один объект,
  перетаскивание → «Вручную», двойной клик → «Авто»; два клиента сходятся (тест двумя
  вкладками); экспорт = экран; скринридер читает сетку; 1024 без горизонтальной прокрутки.

## 4. Общие правила вёрстки (из ревью макетов)

- E2: тонкая линия у панелей, чернильный контур 1.5 только у диалогов и панели задачи агента;
  одна ink-кнопка на экран.
- Стрелки останавливаются в 8 px от объекта (ADR-184), наконечник скруглён (ADR-187).
- Значки темы и языка всегда последние справа в шапке (ADR-194).
- Аватар — одно кольцо цвета участника (ADR-185).
- Бумага стикеров не зависит от темы; хром и сетка — от токенов темы.
- Редкие настройки (фон таблицы) — свёрнуты в панели, на холсте их нет.

## 5. Что ещё не сделано дизайном

- Матрица «компонент × состояние × тема» — состояния перечислены в аннотациях и карточках,
  отдельной матрицы нет.
- 1024 для P5, P12, T4, T12 (это наборы состояний, не экраны); T4 на 1024 — панель выбора
  раскладки нужно положить нижним листом.
- Кликабельный прототип для сессий.
