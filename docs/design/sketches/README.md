# Эскизы: где лежат и как передаются в разработку

Холст «REMO — визуальные направления» — витрина, а не хранилище. Источник эскизов — эта папка.
Холст можно пересобрать из неё целиком; из холста без неё — только вручную.

Почему так: генераторы серий T и P жили во временной папке сессии и пропали при её очистке.
Кадры уцелели только потому, что были опубликованы на холсте. Здесь ничего временного нет.

## Что где

| Путь | Что | Кто меняет |
|---|---|---|
| `sketches/<серия>/*.dc.html` | исходник каждого кадра (HTML 1440 × 900, формат холста) | дизайнер |
| `sketches/<серия>/_notes-<тема>.json` | подписи кадров для холста, если серию строит генератор | генератор |
| `sketches/canvas.json` | раскладка холста: позиции досок, страницы, заметки | снимок с холста |
| `sketches/tools/make_<серия>.py` | генератор серии, если серия строится кодом | дизайнер |
| `sketches/tools/render.mjs` | выгрузка серии в PNG | — |
| `visual/<серия>/*.png` | PNG 2× для разработки: то, что передано | `render.mjs` |
| `tasks/<тема>-handoff.md` | записка передачи: версия, кадры, решения, изменения | дизайнер |

Серии: `directions` (A–E, Main — направления, архив), `F` (первые экраны), `P` (онбординг),
`R` (сценарий), `T` (таблица раздела), `O` (объекты холста), `S` (размеры таблицы и заголовки).

Генератор сейчас есть только у S. У остальных серий источник — сами `.dc.html`: их правят
руками или пишут новому кадру генератор и кладут его в `tools/`.

## Правила

1. **Кадр существует, только если он в репозитории.** Новый эскиз или правка на холсте
   считается сделанной, когда исходник `.dc.html` (и генератор, если он есть) лежит здесь.
   Временная папка сессии — только черновик.
2. **Публикация на холст — после записи сюда, не вместо.** Порядок: правка исходника →
   генератор (если есть) → публикация на холст → свежий `canvas.json` сюда.
3. **Кто правил холст руками** (в редакторе холста, а не через исходник), забирает изменённые
   кадры и `canvas.json` обратно сюда в тот же день. Иначе следующая публикация из репозитория
   затрёт правку.
4. **Имя кадра не меняется после передачи.** Новая версия кадра — то же имя файла.
5. **Генератор не зависит от других генераторов.** Общие примитивы копируются в генератор.
   Именно сцепка `make_o.py → make_t.py` погубила серию O: без пропавшего `make_t.py` её
   генератор не запускается.

## Команды

```bash
python3 docs/design/sketches/tools/make_s.py && THEME=dark python3 docs/design/sketches/tools/make_s.py
```

```bash
node docs/design/sketches/tools/render.mjs S
```

`render.mjs <серия> [фильтр] [--scale=1]` пишет `docs/design/visual/<серия>/<имя>.png`,
по умолчанию в 2× (2880 × 1800). Фильтр — подстрока имени: `render.mjs S S1` выгрузит
только S1 в обеих темах.

## Передача разработчику

Разработчик получает всё из репозитория. Доступ к холсту ему не нужен. Холст приватный,
и Share выдаёт только владелец.

1. **Эскизы приняты.** Владелец подтвердил серию; открытые вопросы закрыты в кадре
   решений серии.
2. **Выгрузка.** `render.mjs <серия>` пишет PNG 2× в `docs/design/visual/<серия>/`.
3. **Записка передачи** `docs/design/tasks/<тема>-handoff.md`. Образец —
   [canvas-objects-handoff.md](../tasks/canvas-objects-handoff.md). Обязательные разделы:
   - где файлы и **версия**: дата, версия холста и коммит, в котором лежат PNG;
   - кадры по этапам вёрстки (обязательные — жирным);
   - решения дизайна — финальными формулировками;
   - новые токены и эталоны, если есть;
   - каждый кадр одним предложением;
   - «Изменения после передачи».
4. **Один коммит:** исходники, PNG и записка вместе. Разработчику дают путь к записке.
5. **Изменение после передачи:**
   - правка исходника, затем перевыгрузка PNG тем же именем;
   - в заголовке кадра пометка «изменено после передачи <дата>»;
   - строка в «Изменениях после передачи» записки;
   - коммит, который называет кадр.

   Разработчик видит изменение в `git log docs/design/visual/<серия>/`.

## Как забрать кадры с холста

Холст — артефакт Claude. Его файлы читает Claude по пути `project/<имя>.dc.html` и
`project/canvas.json` (действие read артефакта). Попросите: «забери с холста серию X в
docs/design/sketches». Сверка: число `.dc.html` в папке серии равно числу досок серии на холсте.
