Редактор на холсте — текстовое поле на 2–6 строк, растёт по тексту. Enter — готово, Shift+Enter и Alt/Option+Enter — перенос, Esc — отмена, Tab — следующий заголовок. Подсказка внизу редактора — тихая, 11 px text-muted, видна только в режиме правки.
Вертикальный заголовок укладывает строки поперёк полосы: каждая строка — отдельная колонка текста. Шапка растёт по самому длинному заголовку (потолок 260 px).
