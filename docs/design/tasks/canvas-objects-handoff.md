# Холст и объекты — передача макетов в вёрстку

Дата: 12 ноября 2026. Статус: **макеты приняты, переданы в вёрстку.**
Задание на дизайн: [canvas-objects-design.md](canvas-objects-design.md) (§9 — список кадров).
Задание на вёрстку: [canvas-objects-build.md](canvas-objects-build.md).

## 1. Где макеты и версия

**Файлы для разработки — в репозитории:** [`docs/design/visual/O/`](../visual/O/) —
76 PNG в 2× (2880 × 1800): `O-<ID>-<state>.png` (светлая) и `O-<ID>-<state>-dark.png`
(тёмная). Полный список с описанием — в §8.

**Версия серии:** 12 ноября 2026, холст «REMO — визуальные направления», версия
`1794521654-49ad`. Источник истины для вёрстки — PNG в репозитории. Холст приватный:
доступ на просмотр выдаёт владелец через Share. Кадр, изменённый после передачи, получает в
заголовке пометку «изменено после передачи <дата>», в этой записке — строку в §9, а PNG
перевыгружается тем же именем.

Где задание на вёрстку просит «ссылку на кадр Figma», давайте имя PNG из
`docs/design/visual/O/`.

## 3. Решения дизайна (кадр F2) — финальные формулировки

| Вопрос | Решение |
|---|---|
| Метка «предел» | Только в момент стопа, у курсора со стороны тяги (`bg-inverse` / `text-inverse`); текст — в бейдже и live-region |
| Блок и группа | Одинаковы; у группы — имя над рамкой и «Группа» в бейдже |
| Рамка блока | Одна по общему боксу, отступ 16, четыре ручки; участники — кольцо 1 px без ручек, отступ 3 |
| Счётчик блока | В существующем бейдже выделения («3 объекта · 2 меняют размер · 1 закреплён») |
| Нечего масштабировать | Рамка без ручек; в бейдже «Можно перенести, но не изменить размер» и состав |
| Пометка «в блоке есть лок» | Не нужна: знак лока на объекте + «1 закреплён» в бейдже |
| Курсоры Shift / Alt | Вариант 1 обоих; стоп-курсор — диагональ + перечёркнутый круг |
| Снап выключен | Индикатора на холсте нет; слово в бейдже и строка подсказок, пока клавиша зажата |
| Напоминание о модификаторах | Только в строке подсказок холста (`CanvasHint`), один раз |
| Момент роста шейпа | Подсветка прироста `selection-fill` 160 мс (без анимации при reduced motion) + live-region «Объект вырос под текст» |
| Потолок роста шейпа | 1 280 px мира; дальше — обрезка и тот же индикатор |
| Индикатор обрезки | Знак «···» в правом нижнем углу внутри объекта, 18 × 14 px экрана на любом масштабе; при выделении — слово в бейдже |
| Чип подписи | Перекрывает линию, без перпендикулярного сдвига; центр — точка пути `labelAt`; ширина 40…240 px |
| Поля «Ш/В» в инспекторе | Нужны, отдельным этапом после этапа 3 (клавиатурный путь к точному размеру) |

Новые числа — потолок 1 280 px и минимум чипа 40 px — записываются в ADR своего этапа
(214 и 213) до кода.

## 4. Токены (кадр F1) — финально

Новые — добавить в `packages/ui/src/tokens/tokens.json`, затем `pnpm --filter @remo/ui tokens`:

| Токен | Значение | Где |
|---|---|---|
| `selection-member` | alpha(`selection-stroke`, 45 %), обе темы | кольцо участника блока |
| `canvas-mark-bg` | rgba(255,255,255,.88), обе темы | фон знака обрезки (содержимое холста не перекрашивается) |
| `canvas-mark-line` | rgba(30,33,54,.28), обе темы | контур знака обрезки |

Остальное — существующие токены; соответствие «элемент → токен» — в F1.

## 5. Эталоны (кадр F3) — финально

Новые: `selection-block.png`, `selection-min-stop.png`, `shape-grow.png`,
`text-overflow.png`, `label-wrap.png` — сняты на пустой доске после «Fit». Эталона роста
пока нет: авторазмер шейпа недомеряет высоту на кадр шрифта, см. §6.
`connectors.png` и `board.png` не изменились: подпись в эталонном кадре короткая, а
однообъектное выделение осталось прежним.

## 6. Что готово и что ещё нет

Готово в дереве (этапы 0–5 и первый шаг 6; не переписывать):

| Этап | Состояние |
|---|---|
| 0 — ADR-209 | `rotation` и `style.fontFamily` удалены из модели, `sanitize`, шаблонов и проекции агента; колонка БД остаётся `0`; тесты |
| 1 — ADR-210 | лок двигается, размер/текст/удаление защищены; помощь, портал и e2e обновлены |
| 2 — ADR-211 | `scaleBoxes`/`minScale`, `transformSelection`, жест блока, кольца участников, счётчик в бейдже, пилюля предела; юнит-тесты, e2e, эталоны `selection-block`, `selection-min-stop` |
| 3 — ADR-212 | `resizedBox(..., { ratio, fromCenter })`, `snapResize`, Shift/Alt/снап в жесте; e2e на пропорции и центр |
| 4 — ADR-213 | перенос 240 px / 3 строки / 8 строк, Enter — строка, чип 40–240, редактор той же ширины; эталон `label-wrap` |
| 5 — ADR-214 | пол 10 px, рост вниз до 1 280 px, таблица не растёт, знак «···» 18 × 14; эталон `text-overflow`. **Открыто:** рост недомеряет высоту на кадр шрифта, нужен замер после загрузки шрифта |
| 6 — шаг 1 | preview коалесцируется в кадр; замер: 120 событий в одной задаче → 1 отрисовка board-слоя |

Проверено: `pnpm verify:fast` зелёный; сценарии жестов, лока, коннекторов и кадров — зелёные.

Ещё не готово:

| Что | Кто | Блокирует |
|---|---|---|
| Отрисовка курсоров (Shift, Alt, стоп) по ТЗ из F2, формат [icons-cursors-spec.md](../icons-cursors-spec.md) | иллюстратор | только внешний вид: жест уже читает модификаторы, до готовности — системный `nwse-resize` |
| Бюджет перетаскивания на 10 000 объектов (p95 полной перерисовки) и fast path, если бюджет нарушен | вёрстка | ничего: текущий замер показывает, что коалесцирование работает; отдельный замер нужен только для большого полотна |

## 7. Приёмка макетов

| Проверка §7 задания | Результат |
|---|---|
| Инварианты §2 | нет кадра, где заметка растёт от текста, шейп растёт вбок или лок нельзя сдвинуть |
| Темы | каждый кадр — светлый и тёмный |
| Токены | всё названо токеном или предложено (F1) |
| Доступность | у «предела», отсутствия ручек и обрезки есть текст (бейдж, live-region, E5) |
| Один вариант | индикатор и курсоры выбраны (F2) |
| Масштаб | индикатор показан на 25 %, 100 %, 200 % (E1); потолок — на 50 % (C5) |
