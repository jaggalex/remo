## 3. Решения дизайна (кадр F2)

| Вопрос | Решение |
|---|---|
| Метка «предел» | Только в момент стопа, у курсора со стороны тяги (`bg-inverse` / `text-inverse`); текст — в бейдже и live-region |
| Блок и группа | Одинаковы; у группы — имя над рамкой и «Группа» в бейдже |
| Рамка блока | Одна по общему боксу, отступ 16, четыре ручки; участники — кольцо 1 px без ручек, отступ 3 |
| Счётчик блока | В существующем бейдже выделения («3 объекта · 2 меняют размер · 1 закреплён») |
| Нечего масштабировать | Рамка без ручек; в бейдже «Можно перенести, но не изменить размер» и состав |
| Пометка «в блоке есть лок» | Не нужна: знак лока на объекте + «1 закреплён» в бейдже |
| Курсоры Shift / Alt | Вариант 1 обоих; стоп-курсор — диагональ + перечёркнутый круг |
| Снап выключен | Индикатора на холсте нет; слово в бейдже и строка подсказок, пока клавиша зажата |
| Напоминание о модификаторах | Только в строке подсказок холста (`CanvasHint`), один раз |
| Момент роста шейпа | Подсветка прироста `selection-fill` 160 мс (без анимации при reduced motion) + live-region «Объект вырос под текст» |
| Потолок роста шейпа | 1 280 px мира; дальше — обрезка и тот же индикатор |
| Индикатор обрезки | Знак «···» в правом нижнем углу внутри объекта, 18 × 14 px экрана на любом масштабе; при выделении — слово в бейдже |
| Чип подписи | Перекрывает линию, без перпендикулярного сдвига; центр — точка пути `labelAt`; ширина 40…240 px |
| Поля «Ш/В» в инспекторе | Нужны, отдельным этапом после этапа 3 (клавиатурный путь к точному размеру) |

Новые числа — потолок 1 280 px и минимум чипа 40 px — записываются в ADR своего этапа
(214 и 213) до кода.

Новые — добавить в `packages/ui/src/tokens/tokens.json`, затем `pnpm --filter @remo/ui tokens`:

| Токен | Значение | Где |
|---|---|---|

| `canvas-mark-bg` | rgba(255,255,255,.88), обе темы | фон знака обрезки (содержимое холста не перекрашивается) |

Остальное — существующие токены; соответствие «элемент → токен» — в F1.

## 7. Приёмка макетов

| Проверка §7 задания | Результат |
|---|---|
| Инварианты §2 | нет кадра, где заметка растёт от текста, шейп растёт вбок или лок нельзя сдвинуть |
| Темы | каждый кадр — светлый и тёмный |
| Токены | всё названо токеном или предложено (F1) |
| Доступность | у «предела», отсутствия ручек и обрезки есть текст (бейдж, live-region, E5) |
| Один вариант | индикатор и курсоры выбраны (F2) |
| Масштаб | индикатор показан на 25 %, 100 %, 200 % (E1); потолок — на 50 % (C5) |
