# Размеры и заголовки таблицы — передача эскизов

Дата: 15 ноября 2026. Статус: **черновик — эскизы ждут приёмки владельцем.** Код по ним
не начинать до ADR по анатомии ручки и числового поля (§9 ТЗ).
ТЗ: [table-size-brief.md](../table-size-brief.md). Порядок хранения и передачи —
[sketches/README.md](../sketches/README.md).

## 2. Решения §10

| Вопрос | Решение |
|---|---|
| Ресайз из тела таблицы | Только с зажатым Alt/Option (подтверждено владельцем). Без модификатора тело — выбор ячейки и перенос объектов; на касании варианта нет |
| Мультивыбор осей | Отдельная задача, после ADR |
| Магнит | Нет; шаг Shift = 40 px |
| Подсказка первого раза | В панели, один раз: «Тяните границу, чтобы изменить размер · Двойной щелчок — авто» |
| Шапка на касании | Длинное нажатие на угол → два разделителя крупно (24 px) |
| Подсказка Shift+Enter | Внизу редактора, 11 px `text-muted`, только в режиме правки |
| «Высота колонки» / «ширина строки» | Не используем; «Высота шапки», «Ширина шапки» — общие для таблицы |

## 3. Токены

Новые, два: `--table-handle-hit` (12 px мыши / 24 px касания) и `--table-band-grip` (20 px).
Цвета — только существующие: `border-focus`, `bg-inverse`, `text-inverse`, `border-strong`,
`bg-panel`.

## 4. Кадры — по одному предложению

| Кадр | Что показывает |
|---|---|
| S1 axis-drag | Тянется любая граница в полосе заголовков и имён; чип «245 px · Вручную», пунктир через таблицу; с Alt — и внутренняя линия тела |
| S2 axis-popover | Поповер оси в пяти состояниях: покой, наведение на подпись, скраб с живым превью, ввод, Авто |
| S3 band-corner | Угол шапки: нижний край — высота шапки, правый — ширина полосы имён; линия через таблицу не перехватывает клики |
| S4 panel | Группа «Размер» в панели: режим → пресеты → число, отдельно подгруппа «Шапка» (общая для таблицы) |
| S5 multiline-edit | Редактор заголовка на холсте: 1–3 строки, подсказка Shift+Enter, вертикальный заголовок |
| S6 multiline-panel | Многострочное поле имени в панели и тег «2 строки» в списке осей |
| S7 auto-vs-manual | Один заголовок в три строки: Авто растит шапку до 72 px, ручные 40 px — одна строка и «…» |
| S8 zoom | 50 % и 200 %: ручка, чип и линии одного экранного размера |
| S9 locked | Только чтение: ручек нет, поля панели выключены с причиной словами |
| S10 number-field | Числовое поле DS: анатомия, восемь состояний, размер касания, поведение |
| S11 handle-grip | Ручка границы и хват угла: зоны попадания, курсоры, фокус клавиатуры |
| S12 redlines | Размеры, порядок слоёв над холстом, зум, движение, два новых токена |
| S13 decisions | Решения по открытым вопросам §10 (таблица §2 этой записки) |

Курсоры на кадрах схематичны; итоговые рисует иллюстратор по
[icons-cursors-spec.md](../icons-cursors-spec.md).
