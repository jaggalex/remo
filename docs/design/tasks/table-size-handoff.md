## 2. Решения §10

| Вопрос | Решение | Статус |
|---|---|---|
| Ресайз из тела таблицы | Не делать в v1: все границы в шапке и в полосе имён и угол закрывают задачу. `Alt/Option` занят — `Alt`+drag панорамирует холст, `Alt` при ресайзе объекта — якорь от центра (ADR-212). Если нужен — другой жест или режим и ADR | **открыт**, ждёт владельца |
| Мультивыбор осей | Отдельная задача после ADR; в v1 выбирается одна ось | рекомендация |
| Магнит | Нет; шаг `Shift` = 40 px | рекомендация |
| Подсказка первого раза | В панели, один раз на пользователя: «Тяните границу, чтобы изменить размер · Двойной щелчок — авто». Закрывается крестиком или сама после первого ресайза | рекомендация |
| Шапка на касании | Те же два separator в углу, зона 24 px, без долгого нажатия. Новый жест (например, long-press) — только после явного «да» и ADR | **открыт**, ждёт владельца |
| Подсказка Shift+Enter | Внизу редактора, 11 px `text-muted`, только в режиме правки | рекомендация |
| «Высота колонки» / «ширина строки» | Не используем; «Высота шапки», «Ширина шапки» — общие для таблицы | рекомендация |

## 3. Токены и метрики

Новые токены, два: `--table-handle-hit` (12 px мыши / 24 px касания) и `--table-band-grip`
(20 px). Цвета — только существующие: `border-focus`, `bg-inverse`, `text-inverse`,
`border-strong`, `bg-panel`.

Сведённые числа (S10, S11, S12):
- числовое поле — высота 32, на касании 44; степперы — 24, на касании 36;
- захват угла — 20×20; сегменты угла и границы — попадание 12 / 24.

Высота шапки по коду: `10 + 16 × строки + 10`, но не меньше 40. Одна строка — 40, две — 52,
три — 68.

## 4. Кадры — по одному предложению

| Кадр | Что показывает |
|---|---|
| S1 axis-drag | Тянется любая граница в полосе заголовков и имён, без модификатора; направляющая через таблицу только визуальная, клик у линии выбирает ячейку |
| S2 axis-popover | Поповер оси в пяти состояниях: покой, наведение на подпись, скраб с живым превью, ввод с выделенным числом, Авто (пустое поле с плейсхолдером) |
| S3 band-corner | Угол шапки — хром, не ячейка; нижний сегмент — высота шапки, правый — ширина полосы имён; иерархия попаданий захвата и сегментов |
| S4 panel | Группа «Размер» для колонки и для строки; «Шапка» — отдельная плашка, общая для всей таблицы |
| S5 multiline-edit | Редактор заголовка в 1–3 строки не шире колонки; правка вертикального заголовка; слово без пробелов в Авто и вручную |
| S6 multiline-panel | Многострочное поле имени (растёт до 4 строк, дальше прокрутка), метка строк только у многострочных, подсказка с полным текстом |
| S7 auto-vs-manual | Три строки: Авто — 68 px, вручную 40 px — одна строка и «…»; до/после удаления текста: Авто сжимается, ручной размер остаётся |
| S8 zoom | 50 % и 200 %: ручка, чип, линии и зона попадания 12 px одного экранного размера; чип не уходит под топбар |
| S9 locked | Заблокированный раздел и роль «Просмотр»: вся группа «Размер» выключена, причина первой строкой, ручек и смены курсора нет |
| S10 number-field | Числовое поле DS: анатомия, восемь состояний, размеры, поведение; `Alt` — только внутри поля |
| S11 handle-grip | Ручка границы и угол: зоны попадания, та же иерархия, что в S3, два separator и порядок `Tab` |
| S12 redlines | Размеры, порядок слоёв, зум, движение и `prefers-reduced-motion`; полная линия — направляющая, не зона попадания |
| S13 decisions | Решения по §10 со статусом: что рекомендация, что ждёт владельца (таблица §2 этой записки) |

Курсоры на кадрах схематичны; итоговые рисует иллюстратор по
[icons-cursors-spec.md](../icons-cursors-spec.md).

## 5. Изменения после передачи

**15 ноября 2026 — ревью S1–S13, правки внесены, версия холста `1794769117-9747`:**
- **S1, S13:** вариант с `Alt` из тела убран, пункт возвращён в открытые. `Alt` занят в коде:
  панорама — `gesturePointerDown.ts:49`, якорь от центра — `gesturePointerMove.ts:163`.
- **S2:** подсказка под режимом зависит от режима; «Авто» — пустое поле с плейсхолдером и
  «Пусто — вернуть Авто»; чип скраба не накрывает подпись; во вводе число выделено.
- **S3, S11:** задана иерархия захвата и сегментов. Сплошной акцент — только у активного
  сегмента. Пометка «угол — хром, не ячейка». Клавиатура: два separator и порядок `Tab`.
- **S4:** панель для колонки и для строки; имя команды убрано; «Шапка» в отдельной плашке.
- **S5:** редактор не шире колонки; правка вертикального заголовка; слово без пробелов.
- **S6:** поле на 3 строки и на 5 (до 4 строк, дальше прокрутка); метка строк только у
  многострочных; подсказка с полным текстом.
- **S7:** до/после удаления текста; высоты по формуле кода (три строки — 68, не 72);
  подпись про минимум 40.
- **S8:** зона попадания на 50 % и 200 %; чип у верхнего края.
- **S9:** выключена вся группа; причина первой строкой; отдельная причина для роли
  «Просмотр»; на границе и в углу — обычный курсор.
- **S10:** чип не накрывает подпись; `Alt` — только внутри поля; размеры сведены с S12.
  Контраст красного текста в тёмной теме — 6,9 : 1 на панели.
- **S12:** числа сведены с S10 и S11; полная линия — не зона попадания;
  `prefers-reduced-motion`.

**15 ноября 2026 — сверка с проверками [table-size-review.md](table-size-review.md),
версия холста `1794769314-8070`:**
- **S5:** перенос строки — `Shift+Enter` или `Alt/Option+Enter`; в тексте `Alt` холст не
  панорамирует.
- **S9:** separator не попадают в порядок `Tab`, стрелки размер не меняют.
- **S11, S13:** на касании — те же два separator в углу (24 px), без long-press; новый жест —
  только после «да» и ADR.
