# REMO · иконки, курсоры, метки

Обзорный лист набора `preview.html` собирается командой `build_preview.py` (раздел «Как
пересобрать») и в репозиторий не кладётся: каждая иконка в 48 (сетка 2 px), 24, 20 и 16 на панели,
холсте и тёмном фоне, полоса в градациях серого, курсоры на трёх фонах и в @2x с хот-спотом,
метки и курсор участника.

Иконки подключены в `@remo/ui` 2.0.0 (ADR-181): `packages/ui/src/icons.ts` генерируется из
`icons/icons.json` командой `build_icons_ts.py` и руками не правится. Курсор участника рисует
`apps/web/src/remoteCursor.ts` по геометрии `cursors/remo-remote-cursor.svg`; метки человека и
агента — компонент `Avatar` в `@remo/ui`.

## Состав

| Папка | Что | Сколько |
|---|---|---|
| `icons/` | `remo-icon-<name>.svg` (мастер 24, линия 2) и `remo-icon-<name>-16.svg` (сетка 16, линия 1.5) | 110 × 2 |
| `icons/icons.json` | `name → { d, fill?, d16, fill16?, group, meaning }`; `d` — та же форма, что `ICONS` в `icons.ts`, `d16` — геометрия на сетке 16 | 1 |
| `icons/mapping.md` | старое имя → новое для всех 47 текущих ключей | 1 |
| `cursors/` | `remo-cursor-<name>.svg` + `@1x.png` + `@2x.png`, хот-споты и fallback в `cursors.json` | 15 |
| `cursors/remo-remote-cursor.svg` | курсор участника: стрелка, узел, метка человека | 1 |
| `marks/` | `remo-mark-person-<s>.svg`, `remo-mark-agent-<s>.svg`, s = 16, 18, 22, 28 | 8 |

## Правила, которые выдержаны

- Сетка 24, рабочая зона 20, концы и соединения скруглённые, один цвет `currentColor`.
- Заливки только у статусов, `lock-on` и меток.
- Все 7 типов объектов различаются силуэтом: лист с текстом, «Т» без рамки, пустой контур,
  рамка с ярлыком, сетка, карточка с полосой, два узла.
- Статусы различаются формой в градациях серого: пустой круг, половина, круг с вырезанной
  галочкой, круг с «!», треугольник с «!», восьмиугольник с крестом.
- Человек — белый круг с одним кольцом цвета участника, агент — квадрат со штриховкой; в сером различаются.
- Каждый курсор — чернила на белом ореоле, читается на холсте, бумажном стикере и тёмном фоне.

## Курсор участника (для painter, Canvas 2D)

Отдаётся геометрией из `remo-remote-cursor.svg` (46 × 40 при 1x):

- стрелка остриём вверх-вправо, заливка чернилами `#1E2136`, белый ореол 5 (обводка за
  заливкой, скруглённые соединения);
- узел ⌀ 4.5 чернилами с белой обводкой 1.5 рядом с остриём;
- метка человека ⌀ 18: белый круг с одним кольцом 1.5 цвета участника (`presence-1…6`,
  ADR-185), инициалы Golos Text 600, 7.5 px, чернилами;
- размер не зависит от масштаба холста; анимации нет;
- ведущий презентации и тот, за кем следуют, — значок `present` / `follow` 12 px слева от
  метки (в файле не нарисован, геометрия — из `icons/`);
- «… печатает» — после ADR: рамка 2 px и каретка цвета участника на объекте.

## Решения по набору

| Требование | Что сделано | Почему |
|---|---|---|
| 16 px — отдельная отрисовка на пиксельной сетке | своя геометрия на сетке 16 (`viewBox="0 0 16 16"`, линия 1.5): узлы сведены на четверти пикселя правилом из `build/snap16.py`, затем весь набор проверен в увеличении 1x | подгонка выполнена правилом, а не руками по каждой иконке; если какой-то знак на 1x покажется мутным, его геометрию 16 можно задать вручную в `build_icons.py` |
| `-on` для `eye` | `eye-on` (залитый зрачок) и `eye-off` | — |
| `-on` для кнопок разметки | нет | нажатое состояние показывает фон кнопки, а не иконка |
| `group-make` | тот же путь, что `group`; `skill-tidy` = `tidy` | одна работа — один знак |
| `sticky` с утолщённой нижней гранью | лист с двумя строками текста | на 16 px утолщение сливается с краем; отличие от `shape` и `card` даёт текст |
| `name` | плашка-пилюля с текстом | вариант «Аа» читался как «AI» |
| курсор участника: метка вдвое меньше стрелки (референс) | метка ⌀ 18 при стрелке 20 | при ⌀ 15 инициалы 6 px не читаются на экране 1x |
| буквы B I U S и инициалы «по Golos Text в кривых» | B I U S нарисованы линией по сетке; инициалы в метках — `<text>` с Golos Text | контуров шрифта в репозитории нет; метки всё равно подставляют инициалы на лету |

## Как пересобрать

Геометрия задана в `build/` — правьте там, а не в SVG. Из корня репозитория:

```bash
python3 -I docs/design/assets/build/build_icons.py docs/design/assets
python3 -I docs/design/assets/build/build_cursors.py docs/design/assets
python3 -I docs/design/assets/build/build_preview.py docs/design/assets
python3 -I docs/design/assets/build/build_icons_ts.py docs/design/assets packages/ui/src/icons.ts
cp docs/design/assets/build/raster.mjs ./.raster.mjs && node ./.raster.mjs docs/design/assets /tmp/remo-preview.png; rm ./.raster.mjs
```

Последняя команда растрирует курсоры в PNG через Chromium из `@playwright/test` и снимает лист.
Её запускают из корня, чтобы Node нашёл пакет.
