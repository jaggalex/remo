# Эталоны дизайн-системы (ТЗ §10.5)

Три экрана, собранные только из компонентов `@remo/ui`, в двух темах и двух плотностях —
12 снимков 1280×720, язык RU, шрифт Inter из пакета.

| Экран | Что проверяет | Файлы |
|---|---|---|
| `board` | выделение 3 стикеров + floating bar, курсоры двух участников, «чужой» и заблокированный стикер, инспектор с источником роли | `board-{light,dark}-{32,28}.png` |
| `share` | строки доступа с источником роли, ссылка для всех включена и выключена | `share-{light,dark}-{32,28}.png` |
| `agent` | диалог агента: бюджет с ошибкой валидации, primary недоступна, права агента | `agent-{light,dark}-{32,28}.png` |

Живые версии: `pnpm dev:web` → `/__ds?view=board|share|agent&theme=light|dark&density=default|compact&lang=ru|en`.

Снимки сделаны Playwright (Chromium) по этим адресам после `document.fonts.ready`.
Сравнение снимков в CI — v0.2 (решение в `packages/ui/docs/delivery.md`); до тех пор
эталоны обновляются вручную вместе с изменением, которое их меняет.
