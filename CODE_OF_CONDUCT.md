# Code of conduct

## Our commitment

We want participation in remo to be a respectful experience for everyone, regardless of
age, body size, disability, ethnicity, gender identity, level of experience, nationality,
personal appearance, race, religion or sexual identity.

## Expected behaviour

- Be direct about the problem, generous with the person.
- Assume good intent; ask before assuming a mistake.
- Give and accept specific, actionable feedback.
- Respect a decision that has an ADR; if you disagree, propose a new record with evidence.

## Unacceptable behaviour

Harassment, insults, discriminatory language, sexual attention, publishing private
information without consent, and sustained disruption of discussion are not acceptable.

## Enforcement

Maintainers may remove, edit or reject contributions and comments that violate this code.
For a report, contact the maintainer privately through the GitHub profile. Reports are
handled confidentially. Consequences range from a warning to a temporary or permanent ban.

This code is adapted from the Contributor Covenant, version 2.1.
