## Две модели

Фрейм и канбан выглядят похоже — оба группируют объекты. Но устроены они по-разному, и это объясняет разное поведение.

| | Фрейм | Канбан |
|---|---|---|
| Что задаёт положение | координаты объекта | ячейка и порядок в ней |
| Двигается вместе с контейнером | да | карточка двигается только между ячейками |
| Можно изменить размер | да, содержимое не масштабируется | нет |
| Можно вынести наружу | да, просто перетащить | нет: карточка всегда в ячейке |
| Может быть концом связи | нет | карточка — да: линия следует за ячейкой |

```
frame                              kanban
┌────────────────────┐             ┌─────────┬─────────┐
│   ●      ●         │             │  card   │  card   │
│          ●         │             ├─────────┼─────────┤
└────────────────────┘             │  card   │         │
                                   └─────────┴─────────┘
objects move with the frame        a card belongs to a cell
```

## Фрейм

Фрейм — контейнер. Объект, центр которого попал внутрь фрейма, становится его частью и двигается вместе с ним; если вынести объект за границу, он снова живёт отдельно. Если фреймы перекрываются, объект входит в меньший. Границы фрейма не обрезают объект — он остаётся видимым, даже если вышел за край.

Фрейм удобен, когда разделов несколько и каждый — законченная мысль: «Спринт», «Бэклог», «Риски».

Размер фрейма меняется угловыми маркерами и означает, сколько доски занимает раздел. Содержимое не масштабируется: объекты остаются того же размера, а после изменения границы принадлежность пересчитывается по центру — объект может войти во фрейм или выйти из него. Минимальный размер — 160 × 120.

## Канбан

Канбан — сетка: колонки задают этап, дорожки — дополнительное деление (например, по команде). Карточка принадлежит ячейке; её положение определяется порядком внутри ячейки, а не координатами.

Поэтому карточка:

- не перетаскивается по свободному холсту;
- соединяется с другими объектами; её конец связи следует за ячейкой;
- создаётся двойным щелчком по ячейке, а не кнопкой «добавить объект».
