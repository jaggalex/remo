## When you need it

You need a screenshot, a photo or a diagram on the board, and you want to work with it as a room object: move it, connect it, make it a slide.

## Before you start

- Permission to edit the room. A visitor on a public link cannot add images.
- A file in one of the supported formats: PNG, JPEG, WebP, GIF or AVIF. SVG and HEIC are not supported in this version.
- Free space in the organisation's storage.

## Steps

1. Add the file in one of these ways:
   - click **Image** on the toolbar on the left and choose one or more files;
   - drag files from Finder or Explorer to the place on the canvas where they belong — the **Drop to add** frame shows how many files you are holding;
   - copy a picture or a screenshot and press `⌘V` / `Ctrl+V`.
2. Wait for the upload to finish. Result: an image object at the drop point or in the centre of the screen; it is selected, and its object bar has **Replace**, **Description**, **Open** and **More**.
3. Resize it by a corner if needed: the proportions are kept.
4. Click **Description** and write what the picture shows. Result: screen readers read it, the lightbox shows it, and the export carries it.
5. Double-click to open the lightbox: the wheel zooms, dragging moves the picture, a double click fits it and `Esc` closes it.

Only the author sees the upload: for everyone else the object appears once it has finished. Nobody sees a half-uploaded object or deletes it by accident.

## Replace and download

- **Replace** on the object bar: the new file goes behind the same object, its size follows the new picture, and its position does not change.
- **Download original** in the **More** menu: this is the original file, not the lighter copy shown on screen. It needs the export grant (`board.export`).
- **Natural size** in the same menu returns the object to the file's own size.

## Check

- The canvas shows the picture, not a grey placeholder.
- A second participant sees the same image in the same place.
- Resizing by a corner does not distort the proportions.
- A PNG export contains the picture.

## Common problems

| Symptom | Cause | What to do |
|---|---|---|
| "The file is larger than 20 MB" | the per-file limit | make the file smaller or save it at a lower quality |
| "This format is not supported" | SVG, HEIC or a damaged file | save it as PNG, JPEG or WebP |
| "The storage is full" | the organisation's quota | free space or change the plan; the **Storage** tab shows what is used |
| "The room already has 500 images" | the per-room limit | delete the pictures you no longer need or use a separate room |
| "Image unavailable" | the file was removed or did not come back from a backup without images | upload it again; the object can stay |
