## When you need it

You need to build a working board from scratch: sections, objects and connectors, not a set of scattered sticky notes.

## Before you start

- A board assigned to you or to a colleague.
- Edit permission.

## Steps

1. Open **More ▾ → Templates…** and choose **Kanban board**, **Roadmap**, **Story map** or **Roadmap example**. Result: the board gets a base structure; the template is added as a copy and does not touch existing objects.
2. If you do not need a template, start with a frame: click **Frame** on the rail and name it after the section it holds. Result: a container; a sticky whose centre lands inside becomes part of the frame.
3. Add sticky notes with the **Sticky note** button on the tool rail and drag them into frames. Result: the sticky notes join the sections and move with them; a sticky note dragged out lives separately again.
4. Select a sticky note and drag from its edge to another sticky note. Result: a connector with an anchor at both ends.
5. Set the connector route on the connector bar: straight, elbow or curved. Result: the diagram stays readable, and lines do not cross unless they must.
6. Select a frame or a shape and drag a corner. Result: the size changed, the frame's contents stayed as they were, and the shape's text fitted the new rectangle.
7. Rename the board in the header. Result: every participant sees the name.

## Check

- Move a frame: the objects inside move with it.
- Resize a frame: the contents are not scaled, and an object whose centre leaves the boundary becomes free.
- Move a sticky note: connectors follow it and do not break.
- The save indicator shows **saved**.

## Common mistakes

| Symptom | Cause |
|---|---|
| A sticky note does not connect | the object is not selected: anchors are visible only on the selected object |
| No second connector between a pair | one pair holds one connector; change the existing one |
| A card does not connect | the card must be visible in its cell; the line follows the cell |
