## When you need it

There are many objects, and you need to see themes or move from an object to its source. Tags give the board one vocabulary; a link on an object leads to an external address or another object.

## Before you start

- You have edit permission on the board.
- The board has an object that needs a tag or a link.

## Tags

1. Select a card or a sticky note.
2. On the **Properties** panel, open **Tags**, enter a name, choose a colour and click **Add**. Result: the tag joins the board vocabulary.
3. Tick the tag under **Tags on this object**. Result: the object carries it.
4. Click **Select (N)** on a tag. Result: every object with the tag is selected; the rest stay in place.
5. Rename or delete the tag. A rename changes the label everywhere; a delete removes it from every object.

## Links

1. Select one object and open **Link**.
2. External: paste `http://`, `https://` or `mailto:` and click **Apply**.
3. Internal: choose a board object and click its **Apply**.
4. **Open** follows the link; **Remove** clears it.

## Check

- Tags and the link are still there after a reload.
- Renaming a tag does not create a second tag.
- An external link opens in a new window; an internal one opens on this board.
- `javascript:` and `data:` are refused.

## Limits

- 50 tags per board, 10 per object.
- A link grants no access: an internal link opens with the normal rights check.
- The server does not fetch or embed an external address.
- An internal link only targets an object on this board.
