## When you need it

The meeting runs on the board: you need to keep to time, pick an option quickly and bring people together.

## Before you start

- A role with the `board.facilitate` permission: editor and above.
- The board has options to vote on.

## Steps: timer

1. Open the timer and choose the duration.
2. Press start. Result: everyone sees the timer and it keeps running even if you closed the panel.
3. If needed, pause, continue or add a minute.

## Steps: voting

1. Select the option objects and open **Facilitation ▾ → Voting**.
2. Set the quota (3 by default), the duration and anonymity. An anonymous session shows only sums; an open session names who voted for what after it ends.
3. Let people vote. Result: counters appear on the objects and a line above the board shows the votes left and the time.
4. End the session or wait for the deadline. Result: the voting buttons disappear and each object keeps its result.
5. Publish the results. Result: a text object appears on the board with a title, places and votes (up to 10), and the number of participants. It is ordinary text with no formatting.

## Steps: gathering people

1. Open **Facilitation ▾ → Shared viewing** and press **Bring everyone to me**. Result: with automatic following (**Follow automatically**) on, participants' view moves at once; otherwise each person gets a "Follow / Stay" invitation.
2. Each person accepts for themselves. Result: everyone ends up in your part of the board.

## Check

- The timer shows the same time for everyone.
- The vote count does not exceed the quota per person.
- After publishing, the result is visible on the board and in the journal.

## Common mistakes

| Symptom | Cause |
|---|---|
| Voting cannot be opened | another session is already open |
| No invitation button | there is nobody else on the board |
| The timer "stands still" | it is paused or the time is up |
