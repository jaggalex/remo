## Когда нужно

Команде нужна кнопка или короткая панель на доске, а писать расширение не требуется.

## Предусловия

- Вы администратор организации.
- Доска принадлежит этой организации: панель показывает приложения её организации.

## Шаги

1. Установите приложение:

```bash
curl -X POST https://boards.example.com/api/orgs/$ORG/apps \
  -H "Content-Type: application/json" --cookie "$SESSION" \
  -d '{"appId":"app.hello"}'
```

2. Откройте доску, затем **Ещё ▾** → **Приложения**.
3. Ожидаемый результат: в панели есть приложение и его кнопка.

## Проверка действия

1. Нажмите **Поздороваться**.
2. Ожидаемый результат: панель показывает «Привет, {ваше имя}!».
3. В аудите организации появится `app.invoked`, в очередь событий — событие `app.invoked`.

## Выключение

1. Выключите приложение:

```bash
curl -X PATCH https://boards.example.com/api/orgs/$ORG/apps/app.hello \
  -H "Content-Type: application/json" --cookie "$SESSION" \
  -d '{"enabled":false}'
```

2. Обновите панель.
3. Ожидаемый результат: приложения в панели нет, его действие отвечает `404`. Включение возвращает всё обратно.

## Частые ошибки

| Симптом | Причина |
|---|---|
| `404 RESOURCE_NOT_AVAILABLE` при установке | такого id нет в реестре продукта |
| `403 FORBIDDEN` | вы не администратор организации |
| Панель пуста | приложение выключено или доска без организации |
