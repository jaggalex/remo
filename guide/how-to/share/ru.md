## Когда нужно

Коллеге нужен доступ к доске, человеку вне команды — возможность посмотреть без аккаунта, а после проекта доступ нужно закрыть.

## Предусловия

- Право делиться доской (`board.share`): у владельца и со-владельца оно есть всегда, у редактора — если политика организации это не запрещает (по умолчанию разрешено).
- Управлять публичной ссылкой может только владелец или со-владелец: у редактора этого блока в диалоге нет.
- Назначить **Со-владельца** может только владелец или со-владелец: это управленческая роль, одного `board.share` недостаточно.
- Адрес коллеги. Роль действует для участников организации. Если аккаунта с такой почтой нет, remo выдаст ссылку-приглашение; если аккаунт есть и человек уже участник организации, доступ начнёт действовать сразу. Иначе сначала нужно членство.

## Шаги: роль для человека

1. Откройте **Поделиться**.
2. Введите адрес коллеги.
3. Выберите роль: **Просмотр**, **Комментарии**, **Редактор**, **Со-владелец**.
   **Комментарии** дают чтение и обсуждение, но не редактирование; **Со-владелец** —
   управление доской и доступом.
4. Нажмите **Добавить**.

Результат: коллега видит доску в своём списке и получает выбранные права.

## Шаги: ссылка для человека вне команды

Нужна роль владельца или со-владельца.

1. В том же диалоге найдите блок **Публичная ссылка**.
2. Нажмите **Включить**.
3. При необходимости задайте пароль и срок действия.
4. Скопируйте ссылку.

Результат: по ссылке доска открывается только для чтения; экспорт и бэкап недоступны.

## Шаги: отозвать доступ

1. Откройте **Поделиться**.
2. Найдите человека в списке доступа и уберите его.
3. Чтобы закрыть доступ по ссылке, нажмите **Выключить** в блоке **Публичная ссылка**.

Результат: открытая вкладка переходит в режим чтения при следующем действии; новые попытки входа отклоняются. Перезагружать страницу не нужно.

## Проверка

- Коллега с существующим аккаунтом видит доску сразу после добавления: отдельного принятия нет. Ссылку-приглашение принимает только тот, у кого ещё нет аккаунта.
- В приватном окне ссылка открывает доску без инструментов редактирования.
- После отзыва коллега не может изменить объект.

## Частые ошибки

| Симптом | Причина |
|---|---|
| Редактор не видит блок ссылки | ссылкой управляют только владелец и со-владелец |
| По ссылке нет экспорта | ссылка даёт только просмотр — это правило, а не дефект |
| Доступ «вернулся» после отзыва | у человека остался второй источник роли: команда или организация |
| Человек вне организации не получил доступ | роли действуют для участников организации: пригласите его или откройте ссылку |
