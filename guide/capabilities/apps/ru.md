## Что даёт

Расширение интерфейса без чужого кода. Приложение объявляет панель — текст, кнопку, поле — и действие этой кнопки. Продукт рисует панель своими компонентами, поэтому внешний код не получает доступ к браузеру.

## Когда использовать

- Нужна одна кнопка или короткая форма на доске.
- Хочется показать результат действия, не уводя человека из продукта.
- Нужна точка входа для интеграции, которую видит команда.

## Как работает

Приложение живёт в реестре продукта. Администратор организации ставит его по id; сервер записывает **свой** манифест в организацию. Панель рисуется по закрытому словарю узлов, все строки берутся из словаря интерфейса. Кнопка вызывает действие приложения на сервере, действие проверяет доступ к доске, пишет аудит `app.invoked` и отправляет событие.

## Пример

Вход: установленное приложение `app.hello`. Действие: человек нажимает **Поздороваться**. Результат: панель показывает «Привет, {имя}!», в аудите появляется `app.invoked`, в очередь событий — `app.invoked`.

## Что можно настроить

Установить, выключить, включить снова или удалить приложение. Выключенное приложение исчезает из панели, его действия отвечают `404`.

## Ограничения

- Доступны только приложения, входящие в сборку продукта: id из реестра. Прислать свою схему нельзя.
- Приложение не рисует произвольный HTML и не загружает внешний код.
- Маркетплейса и сторонних приложений нет.
