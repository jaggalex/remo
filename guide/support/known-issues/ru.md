## Продукт

| Ограничение | Что это значит |
|---|---|
| Нет упоминаний и уведомлений | комментарии читают в комнате; `@` и push не входят в v1 |
| Комментарии только онлайн | черновик ответа сохраняется, отправка ждёт связи |
| Реакции не сохраняются | это живая волна, а не счётчик и не запись |
| Замок — координация, не ACL | прямой клиент с правом записи может обойти UI |
| В PNG/PDF не печатаются решённые треды и больше трёх сообщений | полный текст остаётся в remo |
| Нет прав на объект | доступ только на комнату; объект нельзя закрыть отдельно |
| Комната без владельца закрыта | страница отвечает отказом, в списке комнат её нет; открыть её может закрепление или назначение владельца |
| Публичная ссылка не открывает комнату без владельца | до закрепления ссылка показывает только экран закрепления, а не содержимое |
| Публичная ссылка — только чтение | сама ссылка не даёт экспорт и бэкап: это отдельные права комнаты |
| Повторное закрепление отклоняется | после закрепления владелец меняется только передачей владения |
| Автоматического удаления комнат без владельца нет | комната остаётся закрытой, пока её не закрепят или не назначат ей владельца |
| Одна связь на пару | вторую линию между теми же объектами создать нельзя |
| Одна открытая сессия голосования | на комнате |
| Один эндпоинт вебхука | на организацию |
| Событий об изменениях и удалениях нет | только создание объектов, связи и действия приложений |
| Токен не шире владельца | отдельного «токена организации» нет |
| Приложения только из сборки | свою схему или чужой код установить нельзя |
| Маркетплейса нет | это направление, а не забытая функция |
| Поиск на домашней странице — только по названию | поиска по содержимому всех комнат нет |

## Синхронизация

| Ограничение | Что это значит |
|---|---|
| История отмены живёт во вкладке | после перезагрузки начинается заново |
| Комната без владельца не подключается | до появления владельца сервер отклоняет соединение, поэтому изменения не синхронизируются |
| Очередь офлайна 1000 изменений | дальше ввод останавливается |
| Один процесс | две копии за балансировщиком не увидят комнат друг друга |
| Слияние без «победителя» | правки разных объектов не конфликтуют, одного объекта — применяются в порядке сервера |

## Агенты и интеграции

| Ограничение | Что это значит |
|---|---|
| Комментарии и замок не порождают доменных событий | события есть у создания объектов, связей и действий приложений |
| Одна задача за раз | медленная модель задерживает очередь, не холст |
| Событие доставляется at-least-once | дедуплицируйте по `id` |
| DLQ после 8 попыток | дальше только replay |

## Документация и эталоны

| Ограничение | Что это значит |
|---|---|
| Пиксельный дифф между ОС выключен | визуальный гейт семантический, PNG — для человека |
| В локальном просмотре портала ссылки `/help/…` не работают | помощь живёт в приложении на другом порту |
| Портал — статика | поиск клиентский, без сервера |
