## Что происходит на пределе

| Предел | Поведение |
|---|---|
| 20 000 объектов | новые объекты отклоняются, правки существующих сохраняются; соединение закрывается с `4413` |
| 64 МиБ комнаты | проходят только правки до 16 КиБ; вставка большого фрагмента отклоняется, соединение закрывается с `4413` |
| Кадр больше 16 МиБ | кадр не принимается |
| 256 КиБ/с на сокет | соединение закрывается с `4429`; повтор через 5 с, затем пауза растёт до 60 с |
| 2 МиБ/с на организацию | соединение закрывается с `4429`; повтор через 5 с, затем пауза растёт до 60 с |
| Закрытие `4429` | правки остаются в текущей вкладке и уходят после следующего подключения |
| Закрытие `4413` | правки остаются в текущей вкладке; повтор через 30 с, затем пауза растёт до 5 мин |
| Очередь офлайна, 1000 | ввод в вкладке останавливается, очередь сохраняется до восстановления связи |
| 32 точки на связь | новая точка не добавляется, пока не удалить существующую |
| 500 объектов на задачу | change set отклоняется с объяснением, комната не меняется |
| 300 объектов в плане | план отклоняется до сохранения как `PLAN_TOO_LARGE`; превью нет |
| 10 операций в плане | ответ отклоняется как `TOO_MANY_OPERATIONS`; превью нет |
| 200 объектов в плане | предупреждение `PLAN_LARGE`; применить можно |
| Координата за ±1 000 000 | критическое предупреждение; кнопка «Применить» заблокирована |
| Квота голосов | лишний голос отклоняется, уже отданные остаются |
| 8 попыток вебхука | событие уходит в DLQ, дальше только ручной replay |
| Срок токена больше 365 дней | выпуск отклоняется с `BAD_EXPIRY` |
