## Роли

| Роль | Что может |
|---|---|
| **Просмотр** | читать доску, экспортировать видимую картинку |
| **Комментарии** | читать доску и писать в обсуждение; не меняет объекты |
| **Редактор** | менять содержимое, комментировать, делиться (если политика разрешает), экспортировать, делать бэкап, вести фасилитацию |
| **Со-владелец** | всё, что **Редактор**, плюс управлять доской и назначать со-владельцев |
| **Владелец** | всё, включая передачу владения и удаление |

## Capabilities

| Capability | Просмотр | Комментарии | Редактор | Со-владелец | Владелец |
|---|---|---|---|---|---|
| `board.read` | да | да | да | да | да |
| `board.comment` | — | да | да | да | да |
| `board.edit` | — | — | да | да | да |
| `board.share` | — | — | да* | да | да |
| `board.export` | да | да | да | да | да |
| `board.backup` | — | — | да | да | да |
| `board.facilitate` | — | — | да | да | да |
| `board.manage` | — | — | — | да | да |
| `board.transfer` | — | — | — | — | да |
| `board.delete` | — | — | — | — | да |

(*) Редактор может делиться только если это разрешено политикой организации.

**Со-владелец — управленческая роль.** Назначить, повысить, понизить или снять
со-владельца может только тот, у кого есть `board.manage`. Права `board.share` для этого
недостаточно, даже если человек выдаёт роль самому себе.

## Источники роли

| Источник | Как появляется |
|---|---|
| Прямой грант | роль выдана человеку на доске |
| Команда | человек в команде, команде выдана роль |
| Организация | роль выдана всей организации; гость её не наследует |
| Публичная ссылка | свойство доски; даёт только `board.read` |

При нескольких источниках действует самая сильная роль.

## Чем ссылка отличается от роли

| | Публичная ссылка | Роль на доске |
|---|---|---|
| Нужен аккаунт | нет | да |
| Что даёт | только чтение | набор capabilities по роли |
| Комментарии | недоступны | с `board.comment` |
| Экспорт | запрещён | по роли (`board.export`) |
| Бэкап | запрещён | по роли (`board.backup`) |
| Пароль и срок | да | нет |
